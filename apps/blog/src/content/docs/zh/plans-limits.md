Flareboard Cloud 有三个套餐：Free、Cloud 和 Business。每个套餐对你发送的数据都有每月额度，以及原始数据保留的最长期限。如果你运行自己的 Flareboard 实例，这些都不适用。自托管安装拥有所有功能，没有套餐限制。

## 套餐一览

| | Free | Cloud | Business |
| --- | --- | --- | --- |
| 价格 | $0 | 每月 $19 | 每月 $99 |
| 网站数 | 1 | 套餐不限制 | 套餐不限制 |
| 每月事件数 | 100,000 | 1,000,000 | 5,000,000 |
| 每月会话回放数 | 不包含 | 5,000 | 25,000 |
| 每月日志记录与 Span 数 | 50,000 | 500,000 | 5,000,000 |
| 原始数据最长保留期 | 365 天 | 730 天 | 1,095 天 |
| 会话回放 | 否 | 是 | 是 |
| 热力图 | 否 | 是 | 是 |
| 邮件报告 | 否 | 是 | 是 |
| 团队 | 否 | 是 | 是 |
| CSV 导出 | 否 | 是 | 是 |
| 数据仓库（SQL） | 否 | 是 | 是 |
| 功能开关与实验 | 否 | 是 | 是 |
| 问卷 | 否 | 是 | 是 |

Business 的功能与 Cloud 相同，额度更大，保留期更长。宣传中没有网站数限制的套餐，仍然受 [服务条款](https://flareboard.dev/terms) 所述的合理使用限制约束。

## 哪些计入额度

每项额度按 UTC 日历月计算，并在下个月的第一天重置。

| 额度 | 计入什么 |
| --- | --- |
| 事件 | 你的网站发送的页面浏览、自定义事件和自动采集的交互。 |
| 会话回放 | 被录制的访问。一次访问只在录制开始时计一次。 |
| 日志记录与 Span | 发送到 Flareboard 的 OpenTelemetry 日志和追踪。它们与事件分开计算。 |

向拥有该网站的账号计费。对于团队中的网站，这个账号就是创建它的账号，团队成员在该账号的套餐下使用这个网站。如果该账号被注销，网站会转给团队的另一名所有者或管理员，优先选择付费套餐上的人。见 [团队与权限](/docs/zh/teams)。

## 超出额度

超出额度后 Flareboard 的行为取决于套餐：

- **Free。** 这类数据的采集在达到额度时停止，直到下个月重置。之后发送的数据会被丢弃，不会存储。
- **Cloud 和 Business。** 超出额度后采集仍会继续，最多可超出 20%，然后暂停到下个月。额外的用量不另外收费。

由此得到以下上限：

| | Free | Cloud | Business |
| --- | --- | --- | --- |
| 事件 | 100,000 | 1,200,000 | 6,000,000 |
| 会话回放 | 不包含 | 6,000 | 30,000 |
| 日志记录与 Span | 50,000 | 600,000 | 6,000,000 |

每类数据各自计数、各自停止。达到事件上限不会停止回放或日志，反过来也一样。暂停之前已采集的数据仍然可用。检查使用约一分钟的缓存，所以采集可能超出上限大约一分钟的流量。

## 用量邮件

当某项月度额度用满时，Flareboard 会给账号所有者发邮件。每种数据每月每种邮件只发送一次：

| 何时 | 邮件内容 |
| --- | --- |
| 达到额度的 80% | 你已用掉本月大部分额度。 |
| 达到额度的 100% | 额度已用完。在 Cloud 和 Business 上，采集会继续到上限。 |
| 达到上限 | 这类数据的采集已暂停，到下个月第一天恢复。 |

如果用量直接越过某个档位，只会发送最新的那封邮件。在 Free 套餐上，额度和上限相同，所以你会收到 80% 邮件和暂停邮件。

## 查看用量

在控制台中打开 **订阅**。**本月用量** 为 **事件**、**会话回放** 和 **日志与 Span** 各显示一个进度条，并标明额度重置的日期。接近额度时，进度条会说明已用多少。超出额度后，进度条会告诉你采集还会持续多久、何时停止。**当前套餐** 卡片列出你的套餐包含的功能和原始数据的最长保留期。

## 数据保留

超过保留期的原始事件、会话回放、日志和追踪会被自动删除，大约每小时一次。最长期限由套餐决定（365、730 或 1,095 天）。如果想缩短保留时间，请打开 **网站**，进入网站的 **设置**，找到 **数据保留**，在 **原始数据保留天数** 中输入天数。留空则使用套餐上限。无论什么套餐，日志和追踪最多保留 30 天。由原始事件汇总而来的统计数据可能在网站存续期间一直保留。

如果账号换到最长保留期更短的套餐，超过该上限的原始数据会被删除。

## 升级

1. 打开 **订阅**。
2. 在 **升级** 下，点击 **升级到 Cloud** 或 **升级到 Business**。
3. 从 Free 套餐升级时，你会前往 Stripe Checkout 付款。Flareboard 看不到你的银行卡信息。
4. 你会回到 **订阅** 页面，并看到“订阅已更新，感谢支持！”。

如果你已经使用付费套餐并升级到更高的套餐，新套餐立即生效，Stripe 会在你的下一张账单中按比例结算差价。

## 取消或更改账单信息

在 **订阅** 页面点击 **管理订阅** 可打开 Stripe 的账单门户。有了账单账户后才会出现这个按钮。取消在当前计费周期结束时生效。之后你的账号回到 Free 套餐，Free 套餐不包含的功能将停止工作。你的数据不会因为降级而被删除，但超过 Free 套餐保留期的原始数据除外。如果付款失败，Stripe 会在一段时间内自动重试：期间你的套餐保持不变，**订阅** 页面显示 **待付款**，直到你在 **管理订阅** 中更新支付方式。如果付款最终仍未解决，订阅可能被取消，账号会转为 Free 套餐。费用一般不予退还。详情见 [服务条款](https://flareboard.dev/terms)。

## 自托管安装

自托管的 Flareboard 没有套餐、额度或订阅页面。所有功能都可用。除非你在网站上设置了 **原始数据保留天数**，否则原始事件和回放会无限期保留。日志和追踪仍然最多保留 30 天。额度和用量邮件只存在于 Flareboard Cloud。见 [自托管 Flareboard](/docs/zh/self-host/deploy)。

## 故障排查

- **事件不再到达。** 打开 **订阅** 并查看 **事件** 进度条。如果采集已暂停，它会在下个月第一天恢复，或在你升级后恢复。
- **某个功能是灰色的，或 API 返回“... requires a paid plan.”（例如“Feature flags require a paid plan.”）。** 你的套餐不包含它。回放、热力图、邮件报告、团队、CSV 导出、SQL、功能开关、实验和问卷需要 Cloud 或 Business。对于团队网站，由拥有它的账号的套餐决定：创建它的账号，或者在该账号注销后接手它的团队成员。
- **“Website limit reached”。** Free 套餐只有一个网站。请删除一个或升级。
