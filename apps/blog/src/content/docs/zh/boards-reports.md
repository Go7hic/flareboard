本页介绍用来分享数据结论的几个功能：**看板**（由已保存的洞察和站点统计组成的仪表盘）、**报告**、分享链接、邮件报告、指标告警、**笔记本** 和 **标注**。

## 开始之前

- 一个有数据的网站。见 [快速开始](/docs/zh/quickstart)。
- 如果想在看板上放洞察组件，至少需要一个已保存的洞察。打开 **洞察**，点击 **新建洞察**，构建后点击 **保存洞察**。见 [产品分析](/docs/zh/product-analytics)。
- 编辑需要网站的编辑权限。只读权限下，这些控件是禁用的。
- 在 Flareboard Cloud 上，邮件报告和邮件订阅需要付费套餐（Cloud 或 Business）。自托管安装拥有全部功能，但只有在你的部署配置了邮件发送后，邮件才能使用。见 [套餐与限制](/docs/zh/plans-limits)。

## 1. 看板

在主导航中打开 **看板**。看板是一个组件网格，你可以随时打开并分享。

### 创建看板

1. 点击 **新建看板**。
2. 选择起步方式：
   - **从模板开始**：选择一个网站，点击 **使用模板**。Flareboard 会在该网站上创建模板里的洞察，并立即把它们排布到一个新看板上。模板有 **产品分析**、**网站分析** 和 **收入**。
   - **空白看板**：输入 **看板名称**，选择 **看板时间范围**，添加组件，然后点击 **创建看板**。

### 组件

每个组件是下列之一：

- **站点统计**：一个网站的核心数字和趋势。
- **洞察**：一个已保存的洞察。点击 **添加洞察组件** 并选择一个。

可以为组件设置可选的 **标题** 和 **宽度**：**小**、**中**、**大** 或 **整行**（基于 12 列网格）。在看板上，拖动手柄可以调整组件顺序，拖动右边缘或选择尺寸可以调整大小。要修改看板的内容，点击 **编辑看板**，改动组件后点击 **保存看板**。

### 日期范围和筛选

看板的时间范围可选 **最近 24 小时**、**最近 7 天**、**最近 30 天** 或 **最近 90 天**。你还可以用 **添加看板筛选** 添加看板筛选条件。时间范围和筛选条件对看板上的每个洞察组件都生效。站点统计组件只使用时间范围。

查看时对范围或筛选条件所做的更改是一个未保存的视图，可以通过页面地址分享。点击 **保存为看板默认值** 来保留它们，或点击 **重置** 回到已保存的设置。

### 分享看板

点击 **分享看板**，选择 **有效期**（**永不过期**，或 7、30、90 天），然后点击 **创建链接**。任何拿到链接的人都可以在 `https://flareboard.dev/share/<slug>` 以只读方式查看看板，无需登录。分享视图只显示结果，不会显示已保存的查询或它的筛选条件。链接有访问频率限制。点击链接旁的 **撤销**，即可让它立刻失效。**更多操作** 菜单中的 **复制视图链接** 会复制你当前视图的地址，包括未保存的范围和筛选条件。与分享链接不同，这个地址需要登录。

### 按计划用邮件发送看板

打开 **更多操作**，再打开 **订阅**。输入 **收件人**（最多 10 个地址，用逗号分隔），选择 **频率**（**每日** 或 **每周**）、每周邮件的 **星期** 和 **时间**，然后点击 **订阅**。Flareboard 会发送一封看板摘要邮件，包含关键数字及其相对上一个周期的变化。一个看板或洞察最多可以有 10 个订阅。看板的计划默认使用你浏览器的时区。订阅列表会显示下次发送、上次发送，以及 **已暂停** 状态。这需要付费套餐（Cloud 或 Business）。

你也可以在 **洞察** 页面用 **订阅** 订阅单个已保存的洞察。它的计划默认使用网站的时区。

## 2. 报告

打开 **报告**。选择一个网站，然后打开其中一种报告类型：**漏斗**、**留存**、**用户路径**、**归因**、**多维拆分**、**Web 指标**、**UTM 活动**、**收入**、**行为队列** 或 **目标**。点击 **保存报告**，可以把这种报告类型及其设置（例如漏斗步骤或归因模型）保存到该网站的 **已保存报告** 下。打开已保存的报告，会回到带有相同设置的报告。

## 3. 网站的邮件报告

要定期收到整个网站的摘要：

1. 打开 **网站**，进入网站的 **设置**。
2. 找到 **邮件报告**，打开 **启用邮件报告**。
3. 选择 **频率**（**每日**、**每周** 或 **每月**），并输入 **收件邮箱**，用逗号分隔。
4. 保存。

邮件包含页面浏览量、独立访客、会话和跳出率，访问最多的 10 个页面，最多的 5 个来源，以及与上一周期的对比。它在网站所在时区的 08:00 发出：每日报告每天发送，每周报告在周一发送，每月报告在每月 1 日发送。如果该周期内没有页面浏览也没有会话，Flareboard 会跳过这次发送。邮件报告需要付费套餐（Cloud 或 Business）。

## 4. 指标告警

告警监视一个已保存趋势洞察中的一条线，并在它越过阈值时发送邮件或 webhook。

1. 打开 **洞察**，选择一个已保存的趋势洞察。
2. 在 **告警** 中点击 **新建告警**。
3. 填写：
   - **名称**。
   - **序列**：要监视的线（`A` 到 `E`，或 `formula`）。
   - **检查周期**：**小时**、**天** 或 **周**。
   - **条件**：**值高于**、**值低于**、**增幅超过（%）** 或 **降幅超过（%）**。
   - **阈值**（或 **变化百分比**）。
   - **通知方式**：带地址的 **邮件**，或带 URL 的 **Webhook**。
4. 点击 **创建告警**。

Flareboard 会把网站时区内最近一个完整的周期与你的阈值比较。告警每小时检查一次，每个周期最多检查并发送一次。百分比变化是与前一个周期比较，如果前一个周期为零，则不会发送告警。**暂停提醒…** 可以把告警暂停一天或一周，**历史** 会列出过去的检查以及是否发送了消息。一个网站最多可以有 20 个洞察告警。

webhook 告警是一个带 JSON 请求体的 `POST`：

```json
{
  "type": "insight_alert",
  "websiteId": "YOUR_WEBSITE_ID",
  "alertName": "Signups dropped",
  "insightName": "Weekly sign-ups",
  "condition": "decrease_above",
  "threshold": 20,
  "value": 41,
  "previousValue": 62,
  "series": "Sign-ups",
  "intervalStart": 1760000000000,
  "intervalEnd": 1760604799999,
  "insightUrl": "https://flareboard.dev/insights?insight=INSIGHT_ID"
}
```

webhook URL 必须是公网的 `http` 或 `https` 地址。私有地址、回环地址和内部主机会被拒绝，并且不会跟随重定向。

其他告警放在各自数据所在的位置：[错误告警规则](/docs/zh/error-tracking) 和 [日志告警规则](/docs/zh/logs-traces#5-对日志量设置告警)。

## 5. 笔记本

打开 **笔记本** 来记录发现。笔记本属于一个网站，最多包含 100 个块：

- **文字**：支持标题、粗体、斜体、列表和链接的 Markdown。
- **洞察**：来自同一网站的实时已保存洞察，有自己的日期范围。
- **会话回放**：按 **会话 ID** 链接到某个会话。

点击 **新建笔记本**，输入 **标题**，使用 **添加文字**、**添加洞察** 和 **添加回放链接**，然后保存。有网站访问权限的人都可以阅读，编辑需要编辑权限。

## 6. 标注

标注用来在时间线上标记某些时刻，让指标变化有上下文。打开网站，再打开 **标注**（在 **增长** 下），点击 **新建标注**。输入 **标题**（最多 160 个字符）、可选的描述（最多 1,000 个字符）、**分类**（**备注**、**发版**、**活动**、**事故** 或 **实验**）和 **发生时间**，然后点击 **创建标注**。页面按月份列出标注。点击某一条即可编辑。

## 检查是否生效

1. 用模板创建一个看板并打开它。组件会填入看板时间范围内的数据。
2. 点击 **分享看板**，创建一个链接，并在隐私浏览窗口中打开。你无需登录就能看到这个看板。
3. 对于邮件报告，保存设置并确认收件人。下一封邮件会按上面的计划在 08:00 发出。

## 故障排查

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 组件显示 **无法计算此洞察。** | 洞察已被删除，或它的查询已无法运行 | 编辑看板并替换该组件 |
| **Email subscriptions require a paid plan.** 或 **Email reports require a paid plan.** | 你在 Flareboard Cloud 上使用 Free 套餐 | 更换套餐。见 [套餐与限制](/docs/zh/plans-limits) |
| **A website can have at most 20 insight alerts.** | 已达到告警数量上限 | 删除不再使用的告警 |
| 告警一直不触发 | 在完整周期内没有满足条件，或百分比变化的前一个值为零 | 在 **历史** 中查看最近的值 |
| 分享链接显示 **链接可能已过期。** | 链接已过期或被撤销 | 创建一个新链接 |
