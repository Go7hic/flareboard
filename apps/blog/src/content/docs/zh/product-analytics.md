title: 产品分析
description: 在 Flareboard 控制台中构建趋势、漏斗、留存、路径和粘性分析，并用细分、行为队列、用户画像和账号组对访客分组。
---

产品分析回答关于行为的问题：人们在哪里流失，谁会回来，他们走了哪条路径。每项分析都基于你的网站发送的事件构建，所以请先安装脚本并 [发送几个事件](/docs/zh/events)。如果只想看普通的流量数字，见 [网站分析](/docs/zh/web-analytics)。

有两个地方可以使用：

- 主侧边栏中的 **洞察** 是一个构建器。你选择一个网站，配置趋势、漏斗、留存、生命周期、粘性分析、路径或表格分析，然后保存下来，以便复用、分享或放到看板上。
- 网站的 **行为** 和 **受众** 页面（**漏斗**、**路径**、**留存**、**粘性分析**、**用户画像**、**账号组**、**细分**、**行为队列**）是现成的报告，选项较少。

## 开始之前

- 追踪脚本已安装，你的网站在发送你想分析的事件。漏斗需要 `signup` 和 `purchase` 这样的自定义事件。页面浏览不需要写代码。
- 要跨多次访问识别同一个人，请调用 `identify()`。见 [识别用户](/docs/zh/events#识别用户)。
- 只有查看权限的成员可以阅读所有报告。创建、编辑和删除洞察、细分和行为队列需要编辑权限。

## 洞察

打开 **洞察**，在页头选择一个网站。左侧列表是该网站已保存的洞察。点击 **新建洞察** 来构建一个。

1. 输入 **名称**，需要的话再填写 **描述**。
2. 选择 **类型**：**趋势**、**漏斗**、**留存**、**生命周期**、**粘性分析**、**路径** 或 **表格**。
3. 配置查询。下面各节列出每种类型的选项。
4. 点击 **预览** 下的 **运行** 查看结果。洞察使用 7、30 或 90 天的周期，用结果上方的按钮选择。
5. 点击 **保存洞察**。如果编辑器下方有提示，先处理它，例如 **漏斗至少需要两个步骤。**

保存后的洞察可以再次打开、编辑和删除。已保存洞察的工具栏上有 **分享**（只读链接，见下文）和 **订阅**（按计划发送邮件摘要，在 Flareboard Cloud 上需要 Cloud 或 Business 套餐）。没有编辑权限时，**编辑** 显示为 **探索**，你可以修改查询但不能保存。

### 事件、页面浏览和筛选

大多数类型从一个事件选择器开始，选项如下：

| 选项 | 含义 |
| --- | --- |
| **自定义事件** | 你的某个自定义事件；如果名称留空，则表示任意自定义事件。 |
| **页面浏览** | 一次页面浏览。可用 **任意 URL**、**URL 等于**、**URL 包含** 或 **URL 匹配正则** 缩小范围。 |

点击事件旁的 **条件…** 可以添加只对该事件生效的筛选。**筛选条件** 部分对整个洞察生效。筛选条件之间是“且”的关系，一个洞察最多可以有 10 个。

筛选条件作用于三类属性之一：

| 筛选对象 | 读取内容 |
| --- | --- |
| **事件属性** | 你用 `track()` 发送的属性。 |
| **用户属性** | 你用 `identify()` 发送的属性。 |
| **页面与会话** | 内置值：**页面路径**、**主机名**、**页面标题**、**来源域名**、五个 UTM 字段、**事件名称**、**标签**、**浏览器**、**操作系统**、**设备**、**屏幕**、**国家/地区**、**地区**、**城市** 和 **语言**。 |

运算符：**等于**、**不等于**、**包含**、**不包含**、**匹配正则**、**不匹配正则**、**已设置**、**未设置**、**大于**、**小于** 和 **介于**。数值类运算符只能用于事件属性和用户属性。**匹配正则** 支持有限的语法：字面量、`^` 和 `$`、`.`、`.*`、`.+`、字符类、`\d`、`\w`、`\s`，以及完整模式之间的 `|`（最多五个）。

### 趋势

趋势图显示某件事随时间发生的频率。

- **序列**：最多五个，依次标为 A 到 E。点击 **添加序列** 添加下一个。
- **聚合方式**（每个序列各自设置）：**总次数**、**独立用户**、**独立会话**，或 **属性求和**、**属性平均值**、**属性最小值**、**属性最大值**、**属性中位数**。后五种需要 **数值属性**，也就是你随事件发送的一个数值属性。
- **公式**：按字母组合各个序列，例如 `A / B * 100`。支持数字、`+`、`-`、`*`、`/` 和括号，最长 200 个字符。留空则直接绘制各序列。
- **时间粒度**：**小时**、**天**、**周** 或 **月**。
- **拆分**：按 **事件属性**、**用户属性** 或 **页面与会话** 的值拆分。图表显示最大的 10 个值，其余合并为 **其他**。
- **与上一周期对比**：同时绘制上一个等长周期。

已保存的趋势可以设置告警：打开它，在 **告警** 面板中设置，当某个序列越过阈值时通过邮件或 webhook 通知你。告警每小时检查一次。

示例：注册访客的占比。把序列 A 设为 **页面浏览**，**URL 等于** `/pricing`，**独立用户**。把序列 B 设为自定义事件 `signup`，**独立用户**。输入公式 `B / A * 100`。

### 漏斗

漏斗统计有多少人完成了一系列步骤。

- **步骤**：至少 2 个，最多 20 个。每个步骤是一个自定义事件或一次页面浏览，所以漏斗可以从落地页开始。用 **添加步骤** 添加步骤。
- **转化窗口**：人们完成漏斗的时间限制，从 1 分钟到 90 天，默认 14 天。选择数字和单位（**分钟**、**小时**、**天**、**周**）。
- **步骤顺序**：**按顺序**（默认）或 **任意顺序**。
- **计数对象**：**用户**（默认）或 **会话**。
- **拆分**：按某个属性拆分漏斗。用户归属于他们在第一步时的属性值。

结果显示进入的人数、完成每一步的人数、步骤之间的流失，以及平均和中位数转化时间。点击一个步骤，可列出在该步骤 **已转化** 或 **流失** 的用户或会话。

网站的 **漏斗** 页面是同一种分析的快捷版本：

1. 在网站侧边栏中打开 **漏斗**。
2. 在 **步骤** 中点击 **选择事件…**，按人们应有的顺序至少选择两个事件。如果没有选择步骤，页面会在你同时发送 `signup` 和 `purchase` 时以先 `signup` 后 `purchase` 开始，否则使用你最活跃的三个自定义事件。
3. 在 **选项** 下选择 **统计对象**（默认 **会话**）、**步骤顺序** 和 **转化窗口**。选项范围从 **1 小时内** 到 **90 天内**，默认是 **90 天内**。
4. 还可以添加 **筛选条件** 或选择一个细分。

页面报告 **总转化率**、**进入**、**已完成** 和 **转化时间中位数**。它的步骤只能是事件。要把页面浏览用作步骤，请在 **洞察** 中构建漏斗。

### 留存

留存显示做过某件事的人中，有多少会回来再做一次。

- **队列：执行了以下行为的用户**：起始事件或页面浏览。
- **回访时执行**：算作回访的事件，默认与起始事件相同。
- **周期**：**天**、**周** 或 **月**。
- **周期数**：显示多少个周期，从 8 到 12。
- **计数对象**：**用户** 或 **会话**。

每一行是在该周期首次做起始事件的一批人，每一列是在这么多个周期之后回来的占比。

网站的 **留存** 页面是固定版本：按会话统计的每周页面浏览留存。它在 **队列** 表格上方显示 **用户**、**第 1 周留存**、**第 2 周留存** 和 **第 4 周留存**，表格可以显示为 **占比** 或 **人数**。它需要至少跨越两周的页面浏览数据。

### 生命周期

生命周期把每个区间内活跃的人分成四组。

| 分组 | 含义 |
| --- | --- |
| **新增** | 在这个区间里第一次出现。 |
| **回访** | 当前区间和上一个区间都活跃。 |
| **回流** | 当前区间活跃，上一个区间不活跃，但之前出现过。 |
| **沉睡** | 上一个区间活跃，当前区间不活跃。以负数绘制。 |

选择一个 **事件**（或页面浏览）、**时间粒度** 和 **计数对象**（**用户** 或 **会话**）。生命周期只能在 **洞察** 中使用。

### 粘性分析

粘性分析显示在所选范围内，人们有多少天是活跃的。在 **洞察** 中选择 **事件**（自定义事件或页面浏览，自定义事件名称留空则统计任意自定义事件）和 **计数对象**（**用户** 或 **会话**）。

网站的 **粘性分析** 页面增加了一个汇总：用户或会话的数量、**平均活跃天数**、**活跃 2 天及以上** 和 **活跃对象天数**。表格列出活跃 1 天、2 天等的数量。

### 路径

路径显示访客接下来去哪里。在 **洞察** 中，可以输入可选的 **路径前缀**，例如 `/pricing`，从该页面开始。留空则显示从所有起始页面出发的路径。

网站的 **路径** 页面把路径画成列：

1. 打开 **路径**。
2. 选择 **显示步数**，从 2 到 7，默认是 5。
3. 点击某一列中的页面，跟踪去了那里的访客。点击 **清除选择** 重新开始。

每一列显示访客在该步骤到达的页面，以及相对上一步的 **流失**。该报告读取范围内最近的 5,000 次访问，所以对流量很大的网站，请缩小日期范围来查看某个具体时段。

### 表格

表格按数量对某个维度排名。可选择 **页面**、**事件**、**浏览器**、**国家/地区** 或 **渠道**。

### 分享与订阅

- **分享** 会打开一个对话框，为该洞察创建只读链接。选择链接的 **有效期**，然后点击 **创建链接**。查看者只能看到结果，看不到保存的查询或其筛选条件。点击 **撤销** 可停止访问。
- **订阅** 按计划把洞察的摘要发送到邮箱。选择 **频率**（**每日** 或 **每周**）、日期和时间，以及不超过允许数量的 **收件人**。在 Flareboard Cloud 上需要 Cloud 或 Business 套餐。

## 细分

细分是可以应用到报告上的已保存筛选。在网站侧边栏中打开 **细分**。

1. 点击 **创建细分**。
2. 输入 **名称**，例如 `US visitors on mobile`。
3. 在 **筛选条件** 下，每个条件加一行。选择字段、运算符和 **值**。当每个条件都成立时，访客才算匹配。
4. 还可以添加 **事件与用户属性** 筛选。
5. 点击 **保存**。

字段：**页面路径**（唯一可以用 **包含** 的字段，其余使用 **等于**）、**来源**、**浏览器**、**操作系统**、**设备**、**国家/地区**、**地区**、**城市**、**语言**、**事件名称**、**UTM 来源**、**UTM 媒介**、**UTM 活动**、**主机名** 和 **标签**。点击 **直接编辑 JSON** 可以用 JSON 编辑规则。

保存后，可以在 **概览**、**对比** 和各报告页面的筛选菜单中选择该细分。**细分** 页面上的 **在概览中查看** 会直接跳到已筛选的概览。每个细分显示所选范围内匹配的访客、访问、页面浏览和跳出率。

## 行为队列

行为队列是按人们做过的事情定义的一组人。打开 **行为队列**。

1. 点击 **创建队列**。
2. 输入 **名称**，例如 `Signed up`。
3. 在 **条件（须全部满足）** 下，为第一个条件选择 **事件名称**、**页面路径** 或 **任意事件**。选择 **等于** 或 **包含** 和一个值。**任意事件** 不需要值，而是至少需要一个属性筛选。在第一个条件下面可以添加属性筛选来缩小范围。点击 **添加条件** 可以要求更多事件或页面。额外的条件只能是 **事件名称** 或 **页面路径**。
4. 设置 **活动窗口**。只有窗口内的活动才计入成员资格，默认是最近 30 天。
5. 点击 **保存**。

队列页面显示它的 **成员**，以及其中有多少人在该时段内活跃。**在概览中查看** 会把该队列作为筛选应用到 **概览**。

## 用户画像

**用户画像** 列出日期范围内出现过的已识别用户和匿名访客，显示最近活跃的 100 位。可按姓名、邮箱或 ID 搜索其他人，也可以用 **已识别** 或 **匿名** 筛选。

点击一个人，可以看到他的 **会话**、**访问次数**、**浏览量** 和 **事件**、他的 **属性**、最近的会话和最近的活动。**属性** 是随 `identify()` 发送的特征。有编辑权限时，点击 **编辑属性**，修改 JSON 对象，再点击 **保存属性**。

在你的代码调用 `identify()` 之前，访客一直是匿名的。见 [识别用户](/docs/zh/events#识别用户)。只存储你愿意保留的属性，例如 ID 和套餐名称，不要存密码。

## 账号组

**账号组** 用于分析账号、组织或工作区。请从你的网站发送分组成员信息：

```html
<script>
  flareboard.group('account', 'acme', { name: 'Acme', plan: 'team' })
</script>
```

然后打开 **账号组**，选择一个 **分组类型**（例如 `account`），即可看到每个组的 **用户**、**会话**、**浏览量**、**事件** 和 **最近一次** 活动时间。点击某个组可以看到它的 **账号组属性**、最近的会话和活动。更多内容见 [分组](/docs/zh/events#分组)。

## 检查是否生效

- 漏斗没有数据，通常是因为某个步骤名称与你的网站发送的不一致。请从 **选择事件…** 的列表中选择名称，其中显示了你的网站已发送的自定义事件。
- 在网站至少发送一个自定义事件之前，这个列表是空的。见 [追踪事件](/docs/zh/events)。
- 在 **洞察** 中修改查询后请点击 **运行**，并检查编辑器下方是否有阻止预览的提示。
