网站分析回答关于网站的基本问题：有多少人来过，看了哪些页面，从哪里来，页面加载得有多快。安装 [追踪脚本](/docs/zh/install/script) 后，本页的一切功能都能直接使用，不需要额外设置。

## 开始之前

- 追踪脚本已安装在你的网站上，网站已有页面浏览数据。见 [快速开始](/docs/zh/quickstart)。
- **性能** 页面中的 **Web 指标** 使用同一个脚本，不需要再安装别的东西。
- 在 Flareboard Cloud 上，CSV 导出需要 Cloud 或 Business 套餐。自托管安装拥有全部功能。

从 **网站** 中打开一个网站。网站侧边栏会把它的页面分组。本页涵盖 **概览**、**实时**、**性能**、**对比**、**目标** 和 **UTM 流量**。

## 概览

**概览** 是网站的第一个页面，默认显示 **最近 24 小时**。

### 核心数字

顶部的数字条显示所选时间范围内的五个数字，每个数字都附带与上一个等长时段相比的变化。

| 数字 | 统计内容 |
| --- | --- |
| **访客** | 去重后的访客。访客的统计不使用 Cookie，见 [核心概念](/docs/zh/concepts#访客)。 |
| **访问次数** | 去重后的访问。一次访问是一位访客的一次停留，见 [核心概念](/docs/zh/concepts#访问与会话)。 |
| **浏览量** | 脚本记录的页面浏览。 |
| **跳出率** | 只有一次页面浏览的访问数，除以全部访问数。 |
| **平均访问时长** | 所有访问的时长之和，除以访问数。 |

后两项的计算方式：

- 只有一次页面浏览的访问算作跳出，有两次或更多页面浏览的访问不算。
- 一次访问的时长是它第一个和最后一个事件之间的时间。只有一个事件的访问时长为 0 秒，所以大量单页访问会拉低平均值。
- 两个数字都由计数推算，而不是存成百分比。跳出率是跳出数除以访问数，平均时长是访问总时长除以访问数。

控件旁边的 **N 人在线** 徽标显示最近 5 分钟内活跃的访客数。点击它可打开 **实时**。

### 流量趋势

**流量趋势** 图表绘制 **访客** 和 **浏览量**。48 小时及以内的范围按小时绘制，更长的范围按天绘制。

### 维度卡片

四张卡片列出某个维度的前 8 个值，每张卡片都有标签页。点击卡片底部的 **更多** 可打开 **维度探索**，它把所有维度集中在一起，带有搜索框和 **导出 CSV** 按钮。

| 卡片 | 标签页 |
| --- | --- |
| **页面** | **页面路径**、**入口 URL**、**退出 URL** |
| **来源** | **来源**、**渠道** |
| **环境** | **浏览器**、**操作系统**、**设备** |
| **位置** | **国家/地区**、**地区**、**城市** |

在 **维度探索** 中，**页面路径** 还可以按 **浏览量**、**访客** 和 **平均时长** 排序，也可以查看 **语言**。

卡片下方：

- **访客国家分布** 是一张地图。
- **自定义事件** 列出你最常出现的自定义事件。见 [追踪事件](/docs/zh/events)。
- **流量** 按星期几和小时显示页面浏览量，小时按 UTC 计。

### 渠道

**渠道** 标签页把每次页面浏览归入一个渠道，先匹配到的规则生效。

| 渠道 | 规则 |
| --- | --- |
| **付费广告** | URL 带有 `gclid` 或 `msclkid` 参数，或 `utm_medium` 为 `cpc`、`ppc`、`paid`、`paidsearch`、`cpm`、`display` 或 `banner`。 |
| **邮件** | `utm_medium` 为 `email`、`e-mail` 或 `newsletter`。 |
| **社交媒体** | URL 带有 `fbclid`、`ttclid` 或 `twclid` 参数，或 `utm_medium` 为 `social`。 |
| **自然搜索** | `utm_medium` 为 `organic` 或 `seo`。 |
| **直接访问** | 没有来源页。 |
| **自然搜索** | 来源页是 Google、Bing、Yahoo、DuckDuckGo、百度、Yandex 或 Ecosia。 |
| **社交媒体** | 来源页是 Facebook、Instagram、Twitter 或 x.com、LinkedIn、Reddit、YouTube、TikTok 或 Pinterest。 |
| **引荐** | 其他任何来源页。 |

## 日期范围、对比和时区

使用页面顶部的日期选择器。

- 预设：**最近 24 小时**、**最近 7 天**、**最近 30 天**、**最近 90 天**。**最近 24 小时** 是滚动窗口，其他几项是按网站时区计算的自然日。
- **自定义**：输入 **开始** 和 **结束**，然后点击 **应用**。**结束时间必须晚于开始时间。**
- 你的选择会在浏览器标签页保持打开期间，按网站记住。在你选择之前，**概览**、**性能**、**对比**、**会话回放** 和 **热力图** 显示 **最近 24 小时**；**目标**、**UTM 流量**、**漏斗**、**路径**、**留存** 和 **粘性分析** 显示 **最近 30 天**。

网站的时区在 **设置** 中通过 **站点时区** 设定。自然日预设、图表标签和邮件摘要都使用它，对每个团队成员都一样。

### 与另一时段对比

在 **概览** 中打开筛选菜单（显示为 **全部访客**），勾选 **对比时段**。日期选择器旁会出现一个 **VS** 菜单。

| 选项 | 对比时段 |
| --- | --- |
| **上一周期** | 等长，结束于所选范围的开始处。 |
| **去年同期** | 将所选范围向前平移 365 天。 |

之后每个核心数字下方都会显示对比值。点击 **打开完整对比报告** 进入 **对比** 页面。

## 按细分或行为队列筛选

**概览** 的筛选菜单中也列出你保存的细分。选择其中一个，页面上的所有数字就只统计符合该细分的访客。页面上会出现一条横幅，写着 **细分筛选：NAME**，并带有 **清除细分筛选** 按钮。

行为队列筛选的用法相同。在 **行为队列** 中用 **在概览中查看** 打开一个队列，横幅会显示 **队列筛选：NAME**，并带有 **清除队列筛选**。

报告页面（**目标**、**UTM 流量**、**对比** 和各产品报告）也有细分菜单。创建细分和行为队列的方法见 [细分](/docs/zh/product-analytics#细分) 和 [行为队列](/docs/zh/product-analytics#行为队列)。

## 实时

**实时** 显示网站此刻发生的事情。**实时** 徽标表示页面每秒接收一次更新，**重连中…** 表示已退回到轮询。

- **当前在线**：最近 5 分钟内活跃的访客。
- 最近 30 分钟的 **浏览量** 和 **访客**，以及访问数。
- **热门页面**，以及在线访客中有多少人在这个页面上。
- 一个地球仪，标出在线访客的位置。
- **实时会话**：每位在线访客一行。点击一行可打开该会话。
- 在线访客的 **活跃页面**、**来源** 和 **国家/地区**。

当网站上没有人时，页面显示 **当前没有访客**，并改为显示最近 30 分钟的数据。

## 性能

**性能** 报告由追踪脚本在访客浏览器中测得的 Core Web Vitals。每次页面加载发送一组测量值，在页面被隐藏时或 10 秒后发送，以先到者为准。

数值按 **p75** 显示，即 75% 的页面加载小于或等于这个数字。当至少 75% 的加载为良好时，页面评为 **良好**；当超过 25% 的加载为较差时，评为 **较差**；其余情况为 **待改进**。

| 指标 | 良好上限 | 较差起点 |
| --- | --- | --- |
| **LCP** 最大内容绘制 | 2.5 s | 4 s |
| **INP** 交互到下一次绘制 | 200 ms | 500 ms |
| **CLS** 累积布局偏移 | 0.1 | 0.25 |
| **FCP** 首次内容绘制 | 1.8 s | 3 s |
| **TTFB** 首字节时间 | 800 ms | 1.8 s |

点击数字条中的指标即可绘制它的图表。图表按小时或按天显示 p75，并带有一条“良好”阈值线。图表下方的 **维度拆分** 表把 **LCP**、**INP** 和 **CLS** 按 **页面**、**浏览器** 或 **国家/地区** 拆分，并显示 **样本数**。

如果页面显示 **本时段没有 Web 指标数据**，请扩大日期范围。访客打开装有脚本的页面后，测量值才会出现。

## UTM 流量

**UTM 流量** 显示哪些活动带来了访客。它读取落地页 URL 上的标准参数：

```text
https://example.com/?utm_source=newsletter&utm_medium=email&utm_campaign=spring_sale
```

页面显示 **带标签的浏览量**，以及 **主要来源**、**主要媒介** 和 **主要活动**。卡片按浏览量列出 `utm_source`、`utm_medium`、`utm_campaign`、`utm_content` 和 `utm_term` 的每个值。没有标签的页面浏览归为 **无标签**。没有带标签的流量时，页面显示 **该时段没有带 UTM 标签的流量**。

你也可以按活动筛选：创建一个 [细分](/docs/zh/product-analytics#细分)，条件选择 **UTM 来源**、**UTM 媒介** 或 **UTM 活动**。

## 目标

目标把一个自定义事件与一个每天、每周或每月重置的目标数量相比较。它需要你的网站已经在发送的事件，见 [追踪事件](/docs/zh/events)。

1. 打开 **目标**，点击 **新建目标**。
2. 选择 **事件名称**。
3. 输入 **目标数量**，例如 `100`。
4. 选择 **重置周期**：**每日**、**每周** 或 **每月**。每日目标从 UTC 午夜开始计数，每周目标从周一 UTC 午夜开始计数，每月目标从每月 1 日（UTC）开始计数。
5. 点击 **创建目标**。

为已有目标的事件再保存一个目标，会替换原来的目标。

每个目标显示它的 **进度**、**状态**，以及所选日期范围内的 **完成次数** 和 **转化率**。状态为 **已达成**、**进度正常** 或 **落后**，依据是按匀速推算到目前应有的完成次数。转化率是完成目标的访客占比，最多为 10 个目标提供。**未设目标的事件** 列出其他自定义事件，方便你把其中一个变成目标。

只有查看权限的成员可以看到目标，但不能创建、编辑或删除。

## 对比

**对比** 把两个时段并排放在一起。它使用与 **概览** 相同的日期范围。它的 **VS** 菜单可选择 **上一周期** 或 **去年同期**，**概览** 上的 **打开完整对比报告** 会带上你的选择。

- 五个核心数字显示当前值、变化和上一周期的值。
- 折线图把 **当前** 与对比时段叠加，可看 **访客** 或 **浏览量**。
- **按维度对比** 在两个时段中对某个维度（如 **页面路径**、**渠道** 或 **国家/地区**）排名，并显示每行的变化。**新增** 标记之前没有出现过的值。

## 分享只读链接

分享链接让没有账号的人也能看到网站的概览。

1. 打开网站的 **分享链接** 页面。
2. 点击 **创建分享链接**。
3. 复制链接，它形如 `https://flareboard.dev/share/LONG_RANDOM_ID`。

任何拿到链接的人无需登录，就能以只读方式看到五个核心数字、一张页面浏览量图表和四张维度卡片。查看者可以在 **24 小时**、**7 天**、**30 天** 和 **90 天** 之间切换。在这里创建的链接不会过期。点击链接旁的 **撤销** 可立即停止访问。公开分享链接限制为每个 IP 地址每分钟 60 次请求。

分享链接只显示汇总统计。如果这些数字必须保密，就不要创建分享链接。

## 导出 CSV

**概览** 上的 **导出** 菜单会下载所选范围的 CSV，并应用你当前启用的细分或行为队列筛选。

| 选项 | 内容 | 文件名 |
| --- | --- | --- |
| **浏览** | 仅页面浏览 | `WEBSITE_ID-pageviews.csv` |
| **事件** | 所有事件，包括自定义事件 | `WEBSITE_ID-events.csv` |

列：`createdAt`、`sessionId`、`visitId`、`urlPath`、`eventName`、`referrer`、`country`。文件包含该范围内最新的 10,000 行。如果较早的行被截掉，页面上会提示；缩小日期范围即可导出其余数据。

在 Flareboard Cloud 上，导出需要 Cloud 或 Business 套餐。在 Free 套餐上，**导出** 按钮是禁用的，API 会返回 `403` 和 `CSV export requires a paid plan.`。

要从脚本中导出，请用个人 API 密钥调用控制台使用的同一个端点（见 [REST API](/docs/zh/api)）：

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.flareboard.dev/api/websites/YOUR_WEBSITE_ID/export?type=pageviews&startAt=1760000000000&endAt=1762592000000" \
  -o pageviews.csv
```

| 参数 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `type` | `pageviews` 或 `events` | `events` | 导出哪些行。 |
| `startAt`、`endAt` | 毫秒级 Unix 时间 | 最近 30 天 | 时间范围。 |
| `segmentId` | ID | 无 | 限定为某个已保存的细分。 |
| `cohort` | ID | 无 | 限定为某个行为队列。 |

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| **导出** 是灰色的 | Flareboard Cloud 上的 Free 套餐。请升级到 Cloud。 |
| 跳出率看起来很高 | 单页访问算作跳出。人们读完一页就离开的网站，跳出率本来就高。 |
| **性能** 是空的 | 还没有页面加载上报数据，或范围太窄。见上文。 |
| 分享链接提示可能已过期 | 链接已被撤销，或网站已被删除。请创建新链接。 |
| 完全没有数据 | 见 [故障排查](/docs/zh/troubleshooting)。 |
