---
title: 问卷反馈
description: 在你的网站或托管页面上向访客发起简短的多题问卷，并在对应会话旁查看 NPS、CSAT 和文本回答。
---

问卷在你网站上的一个小组件里一次显示一个问题，也可以放在你用链接分享的托管页面上。回答会连同它来自的页面、会话和访客一起存储，所以你可以从一条回答直接跳到对应的会话。

## 开始之前

- **套餐：** 问卷需要 Cloud 或 Business 套餐。在 Free 套餐上，API 会返回 `403` 和“Surveys require a paid plan.”。自托管安装拥有全部功能，没有套餐限制。
- **角色：** 你需要一个可以编辑该网站的账号。只有查看权限的账号可以阅读结果。
- **追踪脚本：** 要在你的网站上显示组件，请安装 [追踪脚本](/docs/zh/install/script) 或 [npm 包](/docs/zh/install/npm)。托管页面不需要它。
- **PostHog SDK：** 在 Flareboard 中创建的问卷不会通过 PostHog SDK 提供。Flareboard 为 `posthog-js` 提供的配置会关闭问卷，所以请在那里设置 `disable_surveys: true`。请使用 Flareboard 追踪器或托管页面。

## 1. 创建问卷

1. 打开你的网站，然后在侧边栏中打开 **问卷反馈**。
2. 点击 **创建问卷**。
3. 选择一个模板：**空白问卷**、**净推荐值 (NPS)**、**客户满意度 (CSAT)** 或 **开放式反馈**。之后可以修改每个问题。
4. 填写 **名称** 和下面的设置，然后点击 **创建问卷**。

对话框中有实时的 **预览**。分支逻辑在预览中可以运行，并且不会发送任何内容。

### 问题

一份问卷最多有 10 个问题，一次显示一个。每个问题有一个类型。

| 类型 | 访客看到的内容 | 说明 |
| --- | --- | --- |
| **开放式文本** | 一个文本框 | 可选的 **占位提示**。回答在 2,000 个字符处截断。 |
| **评分** | 一排按钮 | **量表** 为 1 到 5、1 到 10 或 NPS（0 到 10），可选 **最低分标签** 和 **最高分标签**。 |
| **单选** | 单选按钮 | 两到 20 个选项，每行一个。不区分大小写，不能重复。 |
| **多选** | 复选框 | 选项规则相同。 |
| **链接 / 行动号召** | 一个打开链接的按钮 | 需要完整的 `http(s)` **链接地址**，以及可选的 **按钮文字**。始终可以跳过。 |

对于两种选择类型，勾选 **添加可自由填写的“其他”选项** 可以增加一个自由填写的回答（最长 500 个字符）。每个问题还可以有 **说明（可选）** 和 **可选（可跳过）** 开关。

### 分支

在 **分支** 下，点击 **添加规则** 来决定下一步是什么。一条规则的意思是：“如果 **任意回答** / **分数介于** / **回答为**，则 **跳转到** 后面的某个问题或 **结束问卷**。”规则按顺序检查，没有规则匹配时，访客会看到下一个问题。规则只能向前跳转。

**净推荐值 (NPS)** 模板先问 0 到 10 分的问题，然后问“你给出这个分数的主要原因是什么？”。**客户满意度 (CSAT)** 模板先问一个 1 到 5 分的问题，当评分是 4 或 5 时结束问卷。

### 在哪里、何时显示

这些设置在 **定向与限制** 下，适用于你网站上的组件。

| 设置 | 作用 |
| --- | --- |
| **触发路径** | 只在这个路径及其下级路径上显示。`/pricing` 匹配 `/pricing`、`/pricing?x=1` 和 `/pricing/team`。留空表示任意页面。 |
| **触发事件** | 只在你的代码用 `flareboard.track()` 追踪了这个事件之后立即显示。留空表示问卷在页面加载时出现。 |
| **延迟弹出（秒）** | 等待 0 到 60 秒后再显示。 |
| **展示规则** | 额外的条件，每行一个。见 [展示规则](#展示规则)。 |
| **展示给多少比例的用户 (%)** | 可以看到问卷的访客比例。同一位访客总是得到相同的结果。默认 100。 |
| **频率** | **每人一次**，或 **间隔后重复**，并设置 **重复间隔（天）**，从 1 到 365。 |
| **达到回答数后停止** | 达到这么多份已完成的回答后，停止显示问卷。 |
| **开始时间**、**结束时间** | 一个时间表。问卷在开始之前和结束之后是隐藏的。 |

同一时间屏幕上只有一份问卷。追踪器会取第一份访客符合条件的问卷，按创建时间从旧到新，并且每个网站只会把最早的 10 份启用中的问卷发送到页面。通过 `flareboard.optOut()` 退出的访客永远不会看到问卷。

#### 展示规则

每行输入一条规则，格式为 `field operator value`。表单接受这些字段：`path`、`event`、`property`、`language`、`country`、`device`（属性写成 `property.KEY`）。它接受这些运算符：`equals`、`contains`、`starts_with`、`ends_with`、`not_equals`、`not_contains`、`exists`、`not_exists`。

追踪器在访客的浏览器中检查规则，并且只认得 `path` 和 `language` 搭配 `equals`、`not_equals`、`contains` 和 `not_contains`。带有它不认得的规则的问卷永远不会显示。其他情况请使用 **触发路径** 和 **触发事件**。

```text
path contains /checkout
language equals en-US
```

### 组件何时出现

追踪器在页面加载后不久检查一次是否有问卷，之后每次你用 `flareboard.track()` 追踪事件后再检查一次。设置了 **触发事件** 时，问卷只能在该事件之后出现。在单页应用中，路由切换后不会自动再次检查。请在路由切换之后调用 `window.flareboard.showSurvey()` 重新检查。

访客可以用 **×** 按钮或 Escape 键关闭组件。如果他们已经回答了某个问题，已有的回答会保存为部分回答。访客完成时，追踪器会发送一个带有属性 `surveyId` 的 `survey_response` 事件，你可以在漏斗和行为队列中使用它。

### 外观

在 **外观** 下选择组件的 **位置**（**右下**、**左下**、**右上**、**左上** 或 **居中**）、**配色**（**浅色**、**深色** 或 **跟随访客系统**）、**按钮颜色**、**提交按钮文字**，以及是否 **显示感谢语** 及其文字。同样的设置也适用于托管页面。

### 托管链接

在 **托管链接** 下，勾选 **启用托管问卷页面**。即使你的网站没有运行追踪脚本，任何拿到链接的人也可以作答。链接是 `https://flareboard.dev/s/SURVEY_ID`；如果你设置了由 3 到 64 个小写字母、数字和连字符组成的 **自定义链接（可选）**，则链接是 `https://flareboard.dev/s/YOUR_SLUG`。加上 `?distinct_id=USER_ID` 可以把回答归到某个已知用户。自托管用户使用自己的控制台地址。

## 2. 查看结果

打开问卷，使用它的三个标签页。

- **结果** 显示核心数字：**回答数**、**完成率**，以及来自第一个评分问题的分数（**NPS**、以 4 分和 5 分评分占比计算的 **CSAT**，或 **平均评分**）。在这之下，每个问题都有自己的细分：分数分布（推荐者 9 到 10 分、被动者 7 到 8 分、贬损者 0 到 6 分）、选项计数、链接点击，以及文本回答的 **情绪分布**（**正向**、**负向**、**中性**）。**页面反馈** 列出产生回答的页面。有两天的数据后，**每日回答数** 会绘制趋势，每个问题还会显示有多少人在它之后离开。
- **回答** 列出当前筛选下最近的 100 份回答，每份都带有指向其会话的链接。回答带有它们来自的页面和会话。
- **设置** 把问卷的定向设置集中在一处。

可以用日期范围、**完整** 或 **部分** 状态、文本搜索和页面筛选来缩小结果。点击 **导出 CSV** 导出当前筛选下的回答（最多 50,000 份，从最早的开始），每个问题一列。按问题统计的结果使用最近的 20,000 份回答，总数和趋势则统计全部。

只有访客通过分支走到问卷末尾，回答才算 **完整**。提前关闭组件会留下一份 **部分** 回答。回答数上限只统计已完成的回答。

自由填写的文本回答按输入原样存储。请告诉访客不要输入密码、支付信息或其他个人数据，并且不要在问卷中设置这类问题。

使用 **停用** 可以停止显示问卷而不删除它，使用 **编辑** 修改它。**删除** 会删除问卷及其所有回答。

## 使用 API

控制台使用 `https://api.flareboard.dev/api/websites/YOUR_WEBSITE_ID` 上的这些端点。请发送 `Authorization: Bearer YOUR_API_KEY`。读取需要 **读取** 权限，写入需要 **写入** 权限。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| `GET` | `/surveys` | 列出问卷。 |
| `POST` | `/surveys` | 创建一份。 |
| `PATCH` | `/surveys/SURVEY_ID` | 更新它，例如 `{"enabled":false}`。 |
| `DELETE` | `/surveys/SURVEY_ID` | 删除它及其回答。 |
| `GET` | `/surveys/SURVEY_ID/responses` | 按问题统计的结果和最近的 100 份回答。筛选参数 `startAt`、`endAt`（毫秒）、`status`（`complete` 或 `partial`）、`q`、`path`。 |
| `GET` | `/surveys/SURVEY_ID/export` | 使用同样筛选参数的 CSV。 |
| `GET` | `/surveys/feedback` | 跨问卷的反馈收件箱。筛选参数 `sentiment`（`positive`、`negative`、`neutral`）、`theme`（`price`、`bug`、`confusion`、`feature_request`、`support`、`performance`、`other`）和 `q`。 |

在定价页上创建一份 NPS 问卷：

```bash
curl -X POST https://api.flareboard.dev/api/websites/YOUR_WEBSITE_ID/surveys \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"template":"nps","triggerPath":"/pricing","sampleRate":50}'
```

返回 `201`，内容是该问卷，包括它的 `id` 和 `questions`。`template` 是 `nps` 或 `csat`。通过 API 创建时，两者都只会创建评分问题，不带控制台模板添加的追问。不使用模板时，请改为发送 `name` 和 `questions`（最多 10 个）。

### 构建你自己的问卷界面

你可以自己渲染问卷，例如在移动应用中。两个调用都发往你的采集地址。

```bash
curl "https://t.flareboard.dev/api/surveys?website=YOUR_WEBSITE_ID"
```

返回 `{"surveys":[...]}`：启用中的问卷，采用追踪器使用的格式，带有 `questions`、`appearance`、`sampleRate` 和 `repeatIntervalDays`。时间表和回答数上限已经应用。它会缓存 60 秒，最多列出 10 份问卷。把每份回答发送到：

```bash
curl -X POST https://t.flareboard.dev/api/surveys/response \
  -H "Content-Type: application/json" \
  -d '{"website":"YOUR_WEBSITE_ID","surveyId":"SURVEY_ID","answers":{"QUESTION_ID":9},"source":"api"}'
```

`answers` 把问题 ID 映射到值：开放式文本和单选用文本，评分用整数，多选用数组，链接用 `"clicked"`。返回 `{"ok":true,"responseId":"...","completed":true}`。发送 `"completed": false` 和你自己的 `responseId`（UUID）可以保存一份部分回答，之后用同一个 `responseId` 再次提交即可完成它。超过 32 KB 的请求体会被拒绝并返回 `413`，已关闭的问卷返回 `409`。完整的字段列表见 [采集 API 参考](/docs/zh/reference/ingest-api)。

## 检查是否生效

1. 用 **开放式反馈** 模板创建一份问卷，不设置触发路径，并让 **展示给多少比例的用户 (%)** 保持 100。
2. 在隐私窗口中打开你的网站。大约一秒后，组件会出现在你选择的位置。
3. 作答。在控制台中重新加载该问卷，**回答数** 显示 1，**回答** 标签页列出你的回答，并带有指向你的会话的链接。

如果你测试两次时组件没有再次显示，这是正常的：选择 **每人一次** 时，浏览器会记住这份问卷。请使用隐私窗口，或从 local 和 session storage 中清除键 `flareboard.survey:SURVEY_ID`。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 组件始终不出现 | 问卷已 **停用**、不在时间表内、超过了回答数上限，或访客已经看过。还要检查 **触发路径**、**触发事件**、**展示给多少比例的用户 (%)**，以及追踪脚本是否在该页面上运行。 |
| 带有展示规则时始终不出现 | 追踪器只认得 `path` 和 `language` 规则。请用 **触发路径** 或 **触发事件** 替换其他规则。 |
| 单页应用路由切换后不出现 | 追踪器在加载时和被追踪的事件之后检查。请在路由切换之后调用 `window.flareboard.showSurvey()`。 |
| 刚创建的问卷缺失 | 只有最早的 10 份启用中的问卷会发送到页面。请停用不再需要的问卷。 |
| 在控制台中的更改没有显示在网站上 | 追踪器配置会缓存大约一分钟。 |
| 提交回答被拒绝并返回 `429` | 回答限制为每个 IP 每分钟 30 次请求，每份问卷每个 IP 每小时 5 次。位于同一个 IP 后面的办公室可能会触及这个限制。 |
| API 返回 `403`“Surveys require a paid plan.” | 网站所有者使用的是 Free 套餐。见 [套餐与限制](/docs/zh/plans-limits)。 |
