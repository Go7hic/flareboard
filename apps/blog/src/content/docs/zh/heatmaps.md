热力图把访客在某个页面上点击的位置和滚动的深度汇总起来。用它来看哪些按钮受到关注，以及人们读到哪里就停下了。热力图基于点击和滚动的样本生成，与任何访客都没有关联。

## 开始之前

- **套餐。** 在 Flareboard Cloud 上，热力图需要 Cloud 或 Business 套餐。在 Free 套餐上，**热力图** 页面显示 **热力图需 Cloud 计划。**，API 返回 `403`。自托管安装没有套餐限制。
- **追踪脚本。** 热力图数据来自 [`script.js`](/docs/zh/install/script)。与 [会话回放](/docs/zh/session-replay) 不同，不需要额外的脚本。
- 数据采集默认是开启的。只有当你想降低或关闭采样，或设置预览页面时，才需要修改设置。

## 数据是如何采集的

追踪脚本在每个页面上监听两件事：

- **点击。** 每次点击都是候选。脚本发送指针在可见窗口内的位置，以及窗口大小。
- **滚动。** 访客停止滚动约 0.4 秒后，脚本计算他们在页面上已经看到的深度（百分比）。只有当这个深度超过该浏览器标签页中此页面已出现过的任何深度时，才会发送一次滚动。

并不是每次点击或滚动都会发送。每一次都独立采样，概率称为采样率，默认是 `0.1`，所以大约保留十分之一的点击和十分之一的滚动。对流量大的页面来说，这已经足够。

位置以 1000 乘 1000 网格上的坐标存储，同时存储设备类别（桌面、手机或平板，取自 user agent）和页面路径（包括 `#` 路由）。计数按天累加。没有任何信息能识别访客。

因为点击是相对于可见窗口而不是整个页面记录的，所以点击之前的滚动不会被计入。请把点击视图理解为“人们在屏幕上点击的位置”，对页头、首屏横幅和首屏上方区域最可靠。

## 设置采样率

可以在两个地方设置采样率。

1. **在控制台中。** 打开 **网站**，进入网站的 **设置**，找到 **热力图采样** 卡片。**配置（JSON）** 框里是：

   ```json
   {"sampleRate":0.1,"enabled":true}
   ```

   `sampleRate` 是 0 到 1 之间的数字。把 `enabled` 设为 `false` 会让脚本不再发送热力图数据。点击卡片的保存按钮。

2. **在 script 标签上。** `data-heatmap-sample-rate` 接受 0 到 1 之间的数字：

   ```html
   <script defer src="https://t.flareboard.dev/script.js" data-website-id="YOUR_WEBSITE_ID" data-heatmap-sample-rate="0.5"></script>
   ```

在网站设置加载完成之前使用这个属性，之后由网站设置接管，浏览器会把它保留大约一分钟。除非你需要在某个页面上用不同的值，否则请在控制台中设置采样率。自托管用户请把 `https://t.flareboard.dev` 换成自己的采集地址。

较高的采样率会让流量低的页面更快填满热力图，同时也会让访客的浏览器发出更多请求。

## 阅读热力图

在网站侧边栏中打开 **热力图**。

1. 选择日期范围，默认是 **最近 24 小时**。
2. 在 **页面** 下选择一个页面。列表显示该范围内有数据的页面，按流量从高到低排列，并附带各自的样本数，最多列出最活跃的 100 个页面。如果该范围内还没有数据，可以在 **页面路径** 字段中输入路径，例如 `/pricing`。
3. 选择 **类型**：**点击** 或 **滚动深度**。
4. 选择 **设备**：**全部设备**、**桌面**、**手机** 或 **平板**。不同设备的布局不同，请逐个对比。

### 点击

每个被记录的位置是一个半透明的圆点。圆点会重叠，并在点击集中的地方叠加，所以越密集的区域看起来越强。图例从 **低** 到 **高**。摘要行显示点击数、设备以及记录点击时的窗口大小，格式为“N 次点击 · 全部设备 · 按 1280×800 视口记录”。圆点会按这个大小缩放，并绘制在页面预览之上。

### 滚动深度

表格列出到达的每个深度，从页面顶部向下，并显示 **滚动事件** 的数量，以及每一行在全部滚动事件中的 **占比**。底部附近有一长串很小的数字，说明很少有人读到那么远。

如果页面没有数据，你会看到 **该页面和时间段暂无热力图数据。** 请换一个页面、设备，或扩大日期范围。

## 页面预览

对于点击视图，控制台会尝试在圆点后面显示你的线上页面。用 **页面预览** 开关可以关闭它，这个选择会记在你的浏览器中。

预览地址按顺序是：

1. **设置** 的 **热力图采样** 卡片中的 **预览 URL（可选）**。设置之后，无论你选哪个页面，预览始终显示这个地址。
2. 否则是你网站的 **域名** 加页面路径，使用 `https`。

预览是你页面在框架中的副本，按记录点击时的窗口大小绘制。该框架处于沙箱中，不会运行你的脚本，所以用 JavaScript 构建内容的页面可能显示为空或只绘制了一半。

### 预览不可用时

在以下情况下，控制台会在纯色背景上显示圆点，并用一条提示取代页面：

| 提示 | 原因 |
| --- | --- |
| **无页面预览：请在设置中填写网站域名** | 网站没有域名，也没有 **预览 URL**。 |
| **页面预览不可用，仅显示叠加层** | 该地址没有响应，或页面在 8 秒内没有在框架中加载出来。 |

当网站发送了 `X-Frame-Options` 响应头，或 Content Security Policy 的 `frame-ancestors` 规则不允许控制台时，浏览器会拒绝在框架中显示页面。很多网站默认就会发送其中之一。离线的预发布主机、拼错的域名，以及需要登录的页面也会失败。

叠加层中的点击位置依然准确，所以热力图仍然有用。要获得预览，可以任选其一：

1. 把 **预览 URL（可选）** 设为你自己域名下一个允许嵌入框架的测试页面。字段旁的提示要求使用同源的测试页面，也就是布局与真实页面相同的简单页面。
2. 或者修改页面的 `X-Frame-Options` 或 `frame-ancestors` 设置，允许 `https://flareboard.dev`（自托管则是你自己的控制台地址）把它嵌入框架。
3. 或者保持预览关闭，对照你保存的截图来阅读点击。

因为可选的 **预览 URL** 会用于每个页面，所以它最适合单个重要页面。对其他页面，请依靠叠加层。

## 检查是否生效

1. 打开你网站的一个页面，随便点击，然后滚动到底部。
2. 在默认的 `0.1` 采样率下，你的大多数测试点击不会被保留。为了快速测试，请在 **热力图采样** 中把 `sampleRate` 设为 `1`，保存，等待大约两分钟让设置到达脚本，然后在点击之前先刷新页面。
3. 打开该网站的 **热力图**，选择页面和 **点击**。你的点击会出现。切换到 **滚动深度** 查看你到达的深度。
4. 测试结束后，把采样率改回较低的值。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| **热力图需 Cloud 计划。** | Flareboard Cloud 上的 Free 套餐。请升级到 Cloud。 |
| API 返回 `Heatmaps require a paid plan.` | 在 Free 套餐上，某个请求把热力图设置中的 `"enabled"` 设为了 `true`。该套餐下 **热力图采样** 卡片是锁定的。 |
| 列表中没有页面 | 该范围内没有采样到点击或滚动。请扩大日期范围，或调高 `sampleRate`。 |
| 列表中没有你预期的页面 | 路径不一致。页面按精确路径和 `#` 路由匹配，所以 `/pricing` 和 `/pricing/` 是不同的页面。 |
| 预览中的点击与按钮错位 | 预览的布局与访客看到的不同，例如设备宽度不同。请选择匹配的 **设备**。 |
| 设置 `"enabled": false` 之后没有数据 | 脚本不再发送热力图数据。请重新设为 `"enabled": true`。 |
