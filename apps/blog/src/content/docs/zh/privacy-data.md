Flareboard 的设计目标是在不使用 Cookie、不存储 IP 地址的情况下衡量网站。本页说明这在实践中意味着什么、哪些设置会改变它、你的数据存放在哪里，以及如何取出或删除数据。它描述的是产品的工作方式。它不是法律意见，也不能代替 [隐私政策](https://flareboard.dev/privacy) 或 [服务条款](https://flareboard.dev/terms)，后两者才是对 Flareboard Cloud 有约束力的文件。

在自托管安装中，所有内容都运行在你自己的 Cloudflare 账号上，由你决定如何处理数据。Flareboard 服务无法访问这些数据。

## 你的角色与我们的角色

对于你的网站所收集的访客数据，是你决定安装 Flareboard 以及收集什么，所以你是控制者。Flareboard 仅为提供服务而处理这些数据，是你的处理者。见服务条款中的 [数据处理](https://flareboard.dev/terms#data-processing)。对于你自己的账户信息，Flareboard 是控制者。如果你网站的访客要行使隐私权利，他们应首先联系你。

## Cookie 与浏览器存储

追踪脚本 **不设置 Cookie**。默认情况下，它把存续期很短的会话信息保存在 `sessionStorage` 中，浏览器会在标签页关闭时清除。只有在以下情况下才使用 `localStorage`：

| 何时 | 存储什么 |
| --- | --- |
| 你为已登录用户调用 `identify()` | 你传入的标识符，使后续事件与该用户关联。 |
| 显示问卷 | 问卷的状态，避免过快再次显示。 |
| 访客选择退出 | 退出的选择。 |
| 网站记住访客（默认关闭） | 一个随机访客 ID，以及你为每个事件注册的事件属性。 |

Flareboard 控制台本身使用一个 Cookie `flareboard_session` 来保持你的登录状态。它是 HttpOnly 和 Secure 的，在上次续期后 7 天过期。

## IP 地址

Flareboard 从不存储 IP 地址。服务会读取请求的 IP 地址，用于计算下面描述的访客哈希和大致位置（国家、地区和城市），以及用于短时间的速率限制，然后丢弃它。登录记录和审计日志同样不包含 IP 地址。托管服务商的技术性请求日志可能包含 IP 地址，并会自动删除，通常在 7 天内。完整的浏览器 user agent 不会被存储，只保留粗略的浏览器、操作系统和设备类型。

通过 PostHog SDK 发送的事件以同样的方式处理。这些数据中的 IP 地址属性和原始 user agent 字符串会被丢弃，不会存储。

## 如何统计访客

为了在不使用 Cookie 的情况下统计独立访客，Flareboard 会对 IP 地址、user agent、网站和一个秘密值计算单向哈希。这个秘密值在每个日历月开始时更换。同一网络上的同一浏览器在一个月内算作一位访客，并且无法在月与月之间关联起来。

### 跨会话识别访客（需手动开启）

如果你希望跨月、跨网络识别回访访客，请开启网站的 **跨会话识别访客** 设置。打开 **网站**，进入网站的 **设置**，找到 **数据采集**。脚本随后会在访客的 `localStorage` 中保存一个随机 ID，并用它代替每月哈希。这个 ID 是随机的，不是由 IP 地址或设备派生的。IP 地址仍然不会被存储。

这会在访客的设备上放置一个标识符，所以根据你的访客所在的地区，你可能需要先取得他们的同意。关闭此设置可以让 Flareboard 保持无 Cookie。你也可以在脚本标签上使用 `data-persistence="false"` 让单个页面保持无 Cookie，例如在访客同意之前。

### Do Not Track 与退出

- 在同一个 **数据采集** 卡片中打开 **遵循 Do Not Track 与 Global Privacy Control**。发送任一信号的浏览器就完全不会被追踪。
- 你可以用 `flareboard.optOut()`、`flareboard.optIn()` 和 `flareboard.hasOptedOut()` 为访客提供退出选项。这个选择会保存在浏览器中。对于已退出的访客，追踪脚本和会话录制器都不会发送任何内容。
- 脚本会忽略大部分自动化流量，例如机器人和爬虫。

## 自动采集绝不收集的内容

自动采集会记录对链接和按钮的点击、表单提交和字段变更，以及页面停留时间和滚动深度。你可以在 **数据采集** 中用 **自动采集点击、表单提交和页面离开** 关闭它。它遵循以下规则：

- 绝不记录访客在表单字段中输入或选择的内容。
- 绝不读取表单字段、密码字段或看起来敏感的元素（例如支付或一次性验证码字段）中的文本。
- 会丢弃看起来像银行卡号、身份证件号码或邮箱地址的文本。
- 对于你在元素上用 `data-fb-no-capture` 或类名 `ph-no-capture` 标记为排除的页面部分，不记录其中任何内容。
- 对每次交互，记录元素类型、它的 id、name 和类名、链接地址、对其在页面中位置的简短描述，以及最多 255 个字符的可见文本。

由于会采集可见文本，请不要在链接或按钮文本中放入个人数据。

## 会话回放的遮罩

会话回放默认关闭，并且需要 Cloud 或 Business 套餐。当你在网站设置的 **会话回放** 下开启它时，**隐私** 步骤控制记录哪些内容：

| 设置 | 效果 |
| --- | --- |
| **遮罩所有输入框** | 默认开启。表单字段中输入的所有内容都会被遮罩。即使关闭此项，密码、银行卡和一次性验证码字段以及看起来敏感的字段仍然会被遮罩。 |
| **遮罩页面上的所有文本** | 遮罩页面上的所有文本。 |
| **遮罩选择器（CSS）** | 替换匹配元素内的文本和输入框。`[data-fb-mask]`、`.fb-mask` 和 `.ph-mask` 始终生效。 |
| **屏蔽选择器（CSS）** | 用同样大小的空盒子替换匹配的元素。`[data-fb-no-capture]`、`.ph-no-capture`、`[data-fb-block]`、`.fb-block` 和 `.ph-block` 始终被屏蔽。 |
| **采样率** | 被录制的会话所占的比例。 |
| **最短访问时长** | 更短的访问不发送任何内容。 |
| **捕获控制台日志** | 默认关闭。存储控制台调用和未捕获错误的级别和消息（最多 1,000 个字符）。邮箱地址、类似银行卡的数字、令牌、标记为密码或机密的值以及 URL 查询字符串会先被移除。 |
| **捕获网络请求** | 默认关闭。存储方法、不含查询字符串的地址、状态、耗时和大小。绝不记录请求头和请求体。 |

页面上显示的文本，除非被遮罩，否则都会被记录，所以请配置回放，避免它捕获你页面上的敏感信息。对于已退出的访客，以及在你选择遵循 Do Not Track 或 Global Privacy Control 时发送这些信号的访客，不会记录任何内容。见 [会话回放](/docs/zh/session-replay)。

## 你自己发送的内容

自定义事件、`identify()` 调用、分组数据、收入值、错误、日志和问卷答案，包含你的代码或你的访客放进去的任何内容。Flareboard 不会过滤其中的个人数据。请使用内部用户 ID 而不是邮箱地址，并且绝不要发送密码、银行卡信息或其他机密。见 [追踪事件](/docs/zh/events)。

## 数据存放在哪里

Flareboard Cloud 运行在 Cloudflare 上。你的数据存放在这些地方：

| 数据 | 位置 |
| --- | --- |
| 网站的分析事件、会话、用户和日志 | 每个网站一个 SQLite Durable Object，因此每个网站的数据都在自己的存储中 |
| 账号、团队、网站设置、看板、开关和其他配置 | Cloudflare D1 |
| 会话回放录制内容和上传的 source map | Cloudflare R2 |

Cloudflare 运营着全球网络，所以数据可能在许多国家的数据中心处理。Flareboard 与哪些服务商共享数据，以及跨境传输的保障措施，见 [隐私政策](https://flareboard.dev/privacy)。Cloud 使用 Cloudflare 提供托管和邮件投递，使用 Stripe 处理付款，使用 Google 和 GitHub 提供可选的登录，并在你使用 AI 助手时使用 DeepSeek。

## 保留与删除

| 数据 | 保留多久 |
| --- | --- |
| 原始事件和会话回放 | 在网站的保留期内保留，之后自动删除。你可以为每个网站设置保留期，最长为套餐上限：Free 为 365 天，Cloud 为 730 天，Business 为 1,095 天。未设置时，使用套餐上限。 |
| 由原始事件汇总而来的统计数据 | 可能在网站存续期间一直保留。 |
| 日志和追踪 | 30 天，如果网站的保留期更短则按更短的算。 |
| 助手对话 | 保留到你删除为止，并在 90 天没有活动后移除。 |
| 登录记录 | 180 天。 |
| 已删除的网站和账户 | 立即从你的账户中移除，30 天后永久清除。 |
| 数据库备份 | 已删除的数据最长可能在备份中保留 30 天。 |

要设置更短的保留期，请打开网站的 **设置**，找到 **数据保留**，填写 **原始数据保留天数**。见 [套餐与额度](/docs/zh/plans-limits)。

要删除一个网站，请打开它的 **设置** 并使用 **删除网站**。它的所有存储数据，包括回放录制内容和存储的 API 密钥，会在 30 天内清除。要注销你的账户及其中的一切，见 [账户安全](/docs/zh/security#注销账户)。在 30 天过去之前，数据仍然存在，所以如果你误删了内容，请立即发邮件到 [support@flareboard.dev](mailto:support@flareboard.dev)。

## 导出你的数据

在 Cloud 和 Business 套餐上，你可以把数据下载为 CSV。自托管安装对此没有套餐限制。

- **事件和页面浏览。** 在网站的 **概览** 中使用 **导出**，并选择 **事件** 或 **浏览**（页面浏览）。导出范围是你选中的日期范围，最多为最新的 10,000 行。API 也提供同样的导出：见 [REST API](/docs/zh/api#导出-csv)。
- **查询结果。** 在网站的数据仓库页面运行一条只读 SQL 查询，然后点击 **导出 CSV**。

事件和页面浏览的导出会记录在网站的审计日志中。

## AI 助手与 MCP

“问问 Flareboard”是仪表盘中的助手，用来回答关于某个网站分析数据的问题。它只在你向它提问时运行，并且只有在你所用实例的运营者启用了它时才可用。使用它时：

- Flareboard 会把你的问题、对话中最近最多 12 条消息、网站的名称、域名和时区，以及助手运行的只读查询的结果，发送给Hangzhou DeepSeek Artificial Intelligence Co., Ltd.。每次查询的结果限制为 100 行和一定数量的字符。它们可能包含事件名称、页面 URL、属性值，以及在问题需要时，你的网站所记录用户的 ID、邮箱或姓名。
- DeepSeek 将这些数据存储在中国的服务器上。根据 DeepSeek 自己的条款，它可能保留输入和输出，并用它们来改进其模型。
- Flareboard 在你的账户中存储你的问题和答案，只有你自己可见，并且不会把它们写入日志。
- 如果你或你的访客受限制向中国传输数据的规则约束，请不要使用该助手，也不要提问那些你不愿与 DeepSeek 共享其结果的问题。

AI 工具通过 [MCP 服务](/docs/zh/mcp) 读取的数据，会按它们的条款发送给你所选的工具和服务商。通过 MCP 所做的变更，例如注释和功能开关的切换，会记录在审计日志中。

## 同意横幅

你的网站是否需要同意横幅，取决于适用于你和你的访客的法律，以及你如何使用 Flareboard。Flareboard 的默认设置不设置 Cookie，也不存储 IP 地址。这对你的网站是否足够，应由你和你的法律顾问决定，本页不替你做这个决定。以下设置对答案的影响最大：

- **跨会话识别访客** 会在访客的设备上存储一个标识符。
- `identify()` 会把你传入的 ID 存储在访客的浏览器中，并把他们的活动关联到某个用户。
- **会话回放** 会记录访客在你的页面上看到和做的事。
- 事件属性、用户 ID 和问卷答案可能包含你选择发送的个人数据。

要在访客同意之前不收集任何内容，请在取得同意后再加载脚本，或者对标识符使用 `data-persistence="false"`，对退出使用 `flareboard.optOut()`。如果你使用 [npm 包](/docs/zh/install/npm)，请设置 `persistence: false`。

## 故障排查

- **同一访客在一个月内被统计了两次。** 每月哈希包含 IP 地址和 user agent，所以同一个人换了网络或浏览器就是另一位访客。这是有意为之的设计。**跨会话识别访客** 会改变这一点，同时带来上面提到的同意方面的取舍。
- **回放中出现了敏感文本。** 把该元素加入 **遮罩选择器（CSS）** 或 **屏蔽选择器（CSS）**，或者开启 **遮罩页面上的所有文本**，然后查看新的录制。
- **你需要删除某一个人的数据。** 访客数据与网站关联，而不是与账号关联。请发邮件到 [support@flareboard.dev](mailto:support@flareboard.dev)，注明网站和访客的 ID。删除网站会移除它的所有数据。
