---
title: 会话回放
description: 录制访问并回看。包括套餐要求、需要安装的两个脚本、隐私和采样设置、录制内容的存放位置，以及如何观看、分享和查找回放。
---

会话回放会记录访客在你网站上看到和做的事（页面切换、点击、滚动和鼠标移动），让你像看视频一样回放这次访问。用它来了解人们为什么会在漏斗中流失，或重现一个错误。录制默认是关闭的，你按网站开启，并决定遮罩哪些内容。

## 开始之前

- **套餐。** 在 Flareboard Cloud 上，会话回放需要 Cloud 或 Business 套餐，Free 套餐没有回放。Cloud 每月包含 5,000 次回放，Business 包含 25,000 次。一次回放就是一次被录制的访问。超出额度后，录制会继续到额度的 120%，之后新的录制会停止，直到下个月。自托管安装没有套餐限制。见 [套餐与限制](/docs/zh/plans-limits)。
- **追踪脚本。** 请先安装 [`script.js`](/docs/zh/install/script)。录制器会读取脚本创建的会话 ID 和访问 ID，并最多等待大约一分钟。
- **存储（自托管）。** 录制内容需要采集 Worker 和 API Worker 上的 `REPLAY_BUCKET` R2 绑定。见 [绑定](/docs/zh/self-host/configuration#绑定)。
- **你能控制的页面。** 脚本要放在你追踪的网站上，而不是 Flareboard 控制台里。

## 1. 开启回放

1. 打开 **网站**，进入网站的 **设置**。
2. 在 **会话回放** 卡片中，打开 **启用会话回放**。
3. 点击卡片的保存按钮。

在 Flareboard Cloud 上，Free 套餐会返回 `Session replay requires a paid plan.`，开关也不会保持开启。在回放开启之前，采集服务会接收录制器的请求并丢弃它们。

## 2. 添加脚本

打开网站的 **设置**，找到 **跟踪代码**，打开 **会话回放安装** 标签页。复制其中的代码片段，也可以使用下面这段，并填入你自己的网站 ID：

```html
<script defer src="https://t.flareboard.dev/script.js" data-website-id="YOUR_WEBSITE_ID"></script>
<script defer src="https://cdn.jsdelivr.net/npm/rrweb@2/umd/rrweb.min.js"></script>
<script defer src="https://t.flareboard.dev/recorder.js" data-website-id="YOUR_WEBSITE_ID"></script>
```

- `script.js` 采集页面浏览和事件。
- rrweb 文件是录制库，必须是 `umd` 构建，它会定义 `window.rrweb`。`dist` 构建是 ES module，在普通的 script 标签中会失败。
- `recorder.js` 需要与 `script.js` 相同的 `data-website-id`。也可以用项目密钥代替网站 ID，见 [核心概念](/docs/zh/concepts#项目密钥)。

自托管用户请把 `https://t.flareboard.dev` 换成自己的采集地址。如果你的网站设置了 Content Security Policy，请在 `script-src` 中放行 `https://cdn.jsdelivr.net` 和你的采集地址，在 `connect-src` 中放行你的采集地址。见 [安装追踪脚本](/docs/zh/install/script#content-security-policy)。

PostHog SDK 在这里不录制会话。控制台为它们提供的代码片段设置了 `disable_session_recording: true`。回放请使用 `recorder.js`。

## 3. 选择录制内容

所有选项都在 **设置** 的 **会话回放** 卡片中。更改一般会在一两分钟内到达访客的浏览器：保存时会清除服务端缓存的设置，而每个浏览器自己的副本最多保留约一分钟。

### 采样

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **采样率** | 100% | 被录制的访问比例。每次访问只决定一次，所以一次访问要么完整录制，要么完全不录。降低它可以节省存储。 |
| **最短访问时长** | **记录所有访问** | 可选 **至少 2 秒**、**至少 5 秒**、**至少 10 秒** 或 **至少 30 秒**。更短的访问不会发送任何内容，这样可以在跳出的访问上节省存储。 |
| **捕获控制台日志** | 关闭 | 存储 `console` 调用和未捕获错误的级别和消息。消息会在 1,000 个字符处截断。邮箱地址、类似银行卡的数字、令牌、`password=` 这类标签后面的值，以及 URL 查询字符串，会先在浏览器中被移除。每个页面最多 300 条。 |
| **捕获网络请求** | 关闭 | 存储 `fetch` 和 XHR 调用的方法、不含查询字符串的 URL、状态、耗时和大小。很长的不透明路径片段会变成 `:redacted`。永远不会读取请求头和请求体。每个页面最多 500 条。 |

### 隐私

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **遮罩所有输入框** | 开启 | 每个输入的值都被替换为等长的星号。关闭后，密码、隐藏、支付和一次性验证码字段，名称、id 或占位提示看起来敏感的字段（例如 `token`、`ssn`、`iban`、`card number`），以及位于遮罩选择器内的内容，仍然会被遮罩。 |
| **遮罩页面上的所有文本** | 关闭 | 把每个文本节点替换为星号。 |
| **遮罩选择器（CSS）** | 空 | 匹配元素内的文本和输入会被遮罩。每行一个选择器，或用逗号分隔。 |
| **屏蔽选择器（CSS）** | 空 | 匹配的元素完全不会被录制。观看者看到的是一个同样大小的空框。 |

页面上显示的文本会原样录制，除非你把它遮罩，所以在开启回放之前，请检查你的页面是否含有个人数据。

有些标记始终有效，不需要任何设置：

| 位置 | 遮罩（文本和输入） | 屏蔽（不录制） |
| --- | --- | --- |
| 你的 HTML | `data-fb-mask`、`.fb-mask`、`.ph-mask` | `data-fb-no-capture`、`.ph-no-capture`、`data-fb-block`、`.fb-block`、`.ph-block` |

```html
<div class="fb-mask">Jane Doe, jane@example.com</div>
<form data-fb-block>...</form>
```

设置中无效的选择器会被忽略，内置的选择器始终生效。

点击 **编辑原始 JSON** 可以一次修改所有设置。键包括 `sampleRate`（0 到 1）、`minDurationSeconds`（最大 60）、`maskInputs`、`maskAllText`、`maskSelectors`、`blockSelectors`、`captureConsole` 和 `captureNetwork`。点击 **应用 JSON**，然后保存该卡片。

### 同意与 Do Not Track

- 通过 `flareboard.optOut()` 退出的访客不会被录制。访问期间退出，会停止录制并丢弃尚未发送的内容。见 [追踪事件](/docs/zh/events)。
- 在 **数据采集** 卡片中开启 **遵循 Do Not Track 与 Global Privacy Control**，或在 script 标签上加 `data-respect-dnt`，发送这两种信号之一的浏览器不会被录制。

如果录制前需要征得同意，请在访客同意之后，再把 `recorder.js` 和 rrweb 脚本添加到页面中。

## 录制数据存放在哪里

录制数据以分块的形式发送到采集地址的 `/api/record`，每 5 秒、每 200 个事件以及页面被隐藏或关闭时各发送一次。每个分块限制为 512 KB。

- 分块存放在 R2 存储桶中，路径是 `WEBSITE_ID/VISIT_ID/CHUNK_NUMBER`。默认配置下存储桶名为 `flareboard-replays`。
- 每个分块的一条小索引行，以及每次访问的摘要（时长、点击数、控制台和网络条目数），保存在网站的数据存储中。回放列表读取的就是这些摘要。

机器人会被忽略。只有在你开启了这些选项时才会保留控制台和网络条目，服务端在存储分块之前会丢弃其他所有字段。

### 数据保留

录制内容会与它所属的原始事件一起，在超过网站的保留期时被删除，大约每小时一次。在 **设置** 的 **数据保留** 下通过 **原始数据保留天数** 设置。留空则使用套餐的最大值：Free 为 1 年，Cloud 为 2 年，Business 为 3 年。自托管安装会一直保留录制内容，直到你设置一个期限。R2 对象会先于其索引行被删除。删除网站会在 30 天内清除其录制内容。见 [隐私与数据](/docs/zh/privacy-data)。

## 观看回放

在网站侧边栏中打开 **会话回放**。

1. 选择日期范围，默认是 **最近 24 小时**。
2. 用 **显示**（**全部回放**、**有问题的回放**、**有错误的回放**、**有日志的回放**、**有 AI 调用的回放**）、**排序**（**最新优先**、**最早优先**、**时长最长优先**、**时长最短优先**、**最活跃**、**错误最多**）、**时长** 和 **用户（distinct ID）** 缩小列表。**更多筛选** 增加了 **访问过的 URL 包含…**、**触发过的事件（名称）**，以及国家、设备或浏览器等属性筛选。
3. 点击一次访问。每一行显示入口页面、时长、页面数、点击数和错误数。

### 播放器

| 控件 | 作用 |
| --- | --- |
| 播放和暂停 | 按钮、点击页面，或按 `Space`。 |
| 进度条 | 点击或拖动来定位。灰色部分是空闲时段，圆点是错误、事件等标记。 |
| **播放速度** | 0.5x、1x、2x、4x 或 8x。 |
| **跳过空闲** | 默认开启。播放时会跳过空闲时段。 |

键盘快捷键，在你没有在输入框中打字时可用：

| 按键 | 操作 |
| --- | --- |
| `Space` 或 `K` | 播放或暂停 |
| 左右方向键 | 后退或前进 5 秒 |
| `Shift` + 左或右方向键 | 上一个或下一个标记 |
| `<` 和 `>` | 减速或加速 |
| `S` | 切换跳过空闲 |

视频旁边的 **回放时间线** 按播放进度列出发生的事情。可以用 **全部**、**控制台**、**网络**、**事件** 和 **页面** 筛选。点击一个条目可以跳转到那里。除非你开启了对应的捕获，否则 **控制台** 和 **网络** 是空的。同一会话中的自定义事件、错误和日志也会显示。

### 保存、复制与分享

- **保存** 会把回放放入 **已保存** 列表，即使它超出了列表的日期范围也会保留。需要编辑权限。
- **复制链接** 会复制一个指向当前播放时间点的控制台链接。只有能登录该网站的人才能打开。
- **分享** 会创建一个公开链接，无需登录即可播放这一条回放。选择过期时间（**永不**、**1 天后**、**7 天后** 或 **30 天后**），点击 **创建并复制链接**，并用 **链接从 TIME 开始播放** 让链接从当前时间开始播放。创建和撤销链接需要编辑权限。链接形如 `https://flareboard.dev/shared/replay/TOKEN`。点击 **撤销** 可停止分享。拿到链接的人能看到录制内容中的一切，包括控制台和网络条目，所以请谨慎分享。

## 找到某个错误对应的回放

1. 打开 **错误**，再打开一个错误，点击 **查看会话**。
2. 在会话页面上，点击 **观看回放**，它会打开该会话最近的一次录制。

也可以反过来操作。在 **会话回放** 中，在 **显示** 下选择 **有错误的回放**，可列出遇到错误或记录了控制台错误的访问。对应的行会显示错误徽标，时间线上也会标出这些错误。

只要访问被录制过，每个会话页面上都有 **观看回放** 按钮。

## 检查是否生效

1. 确认 **启用会话回放** 已开启并保存。
2. 在新标签页中打开你的网站，点击几秒钟，然后刷新或关闭页面，让最后一个分块发出。
3. 打开 **会话回放**。这次访问会连同入口页面一起出现。点击它并按下播放。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| **该站点未启用会话回放。** | 回放没有开启。点击 **打开设置** 并把它打开。 |
| **Session replay requires a paid plan.** | Free 套餐。请升级到 Cloud。 |
| 列表中什么也没有 | 缺少脚本，访问被采样率或最短时长跳过，或者访客已退出，或在网站遵循 Do Not Track 时发送了该信号。请在网络面板中检查对 `/api/record` 的请求。 |
| `recorder.js` 运行了但什么也没录到 | rrweb 脚本没有加载，或构建不对。请使用上面的 `umd/rrweb.min.js` 地址，并在 Content Security Policy 中放行它的主机。 |
| 打开访问时提示 `No replay events found.` | 存储中没有这些分块。自托管安装请检查是否绑定了 `REPLAY_BUCKET`。 |
| 控制台和网络标签页是空的 | 这些捕获是关闭的。请在 **会话回放** 卡片中开启。 |
| 回放中有些地方是空白的 | 被屏蔽的元素显示为空框。请检查 **屏蔽选择器（CSS）** 和 `data-fb-block` 标记。 |
| 本月剩余时间里新的访问不再出现 | 月度额度和它 20% 的宽限量已用完。已在进行的录制会完成，新的录制下个月恢复。 |
