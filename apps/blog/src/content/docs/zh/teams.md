团队让多个人可以共同使用同一批网站。团队的网站、看板、链接和像素会与每个成员共享，成员的角色决定他们是可以修改内容，还是只能查看。

## 开始之前

- 在 Flareboard Cloud 上，团队需要 Cloud 或 Business 套餐。在 Free 套餐上，**创建团队** 和 **加入团队** 按钮是禁用的，控制台会提示“团队功能需 Cloud 计划。”检查针对的是你自己的账号，所以加入团队的人也需要 Cloud 或 Business 套餐。见 [套餐与额度](/docs/zh/plans-limits)。
- 自托管安装的团队功能没有套餐限制。

## 角色

团队有四种角色。下面的角色名称与控制台显示的一致。

| 角色 | 在 API 中 | 可以做什么 |
| --- | --- | --- |
| **所有者** | `team-owner` | 管理员能做的一切，另外可以修改其他所有者的角色、移除所有者、要求开启双重验证，以及删除团队（删除团队只能通过 API 进行）。 |
| **管理员** | `team-manager` | 成员能做的一切，另外可以向团队添加网站、查看邀请码、修改成员的角色（不能改为所有者，也不能修改所有者的角色）、移除成员，以及查看团队活动日志。 |
| **成员** | `team-member` | 查看团队的网站和分析数据，并可以修改：设置、功能开关、实验、看板、目标和其他配置。成员还可以删除团队的网站。 |
| **只读** | `team-view-only` | 查看团队的网站和分析数据。不能修改任何内容。 |

通过邀请码加入的人起初是 **只读**。之后由所有者或管理员修改其角色。

团队始终至少有一名所有者。最后一名所有者不能被降级或移除。只有所有者才能把某人设为所有者，或修改、移除现有的所有者。

一个人自己的账号也可以是只读的，这是一个全局设置（`view-only` 角色）。它优先于团队角色。只读账号即使是所有者，也不能修改团队的网站。

## 1. 创建团队

1. 在控制台中打开 **团队**，点击 **创建团队**。
2. 输入 **团队名称**，然后点击 **创建**。

你会成为团队的 **所有者**。

## 2. 添加成员

Flareboard 不发送邮件邀请。成员通过团队的邀请码加入：

1. 以所有者或管理员的身份打开 **团队** 并选择该团队。在 **邀请码** 下点击复制按钮。
2. 通过私密渠道把邀请码发给你的队友。任何拿到邀请码的人都可以以 **只读** 身份加入团队。
3. 队友登录后打开 **团队**，点击 **加入团队**，在 **使用邀请码加入** 对话框的 **邀请码** 中粘贴邀请码，然后点击 **加入团队**。
4. 在团队的 **成员** 表中，从下拉菜单修改他们的 **角色**。

邀请码为八个字符。每个 IP 地址每分钟最多尝试加入 10 次。控制台无法更改团队的邀请码，所以不想再保留的成员请在 **成员** 表中移除。

## 3. 添加团队网站

一个网站要么属于某个人，要么属于某个团队。创建属于团队的网站：

1. 打开 **团队** 并选择该团队。
2. 在 **网站** 下点击 **添加网站**。所有者和管理员可以执行此操作。
3. 输入 **名称** 和 **域名**，然后点击 **创建网站**。

Flareboard 会打开新网站的设置页和它的安装代码。从此，团队的每个成员都能看到这个网站。安装脚本见 [快速开始](/docs/zh/quickstart)。

团队网站以创建它的账号作为计费所有者。该账号的套餐和功能决定网站能使用什么，网站的事件计入该账号的月度额度。成员在该套餐下使用这个网站。因此，创建团队网站的人应当是你希望使用其套餐的那个人。如果该账号被注销，网站会转给团队的另一名所有者或管理员（优先选择付费套餐上的人），并在其套餐和额度下继续收集数据。转移之前已计入的用量仍留在被注销的账号上。见 [套餐与额度](/docs/zh/plans-limits)。

网站没有移动或转移操作。在个人账号下创建的网站一直是个人的，在团队中创建的网站则一直属于团队。要把网站放进团队，请在团队中创建它，并安装新的网站 ID。

团队的 **链接与像素** 以同样的方式共享。打开团队并点击 **链接与像素**。

## 要求开启双重验证

所有者可以要求每个成员使用双重验证：

1. 先为你自己的账号开启双重验证，位置在账户菜单的 **安全** 下。见 [账户安全](/docs/zh/security)。
2. 打开 **团队** 并选择该团队。在 **安全** 下，打开 **要求开启双重验证**。

此后，没有开启双重验证的成员在开启之前无法访问团队的网站。开启该要求后（对所有者则始终如此），团队会显示 **已开启 2FA 的成员** 数量，**成员** 表中会多出一列 **双重验证**，为每个人显示 **已开启** 或 **未开启 2FA**。受影响的成员会看到一条通知，说明团队要求开启双重验证，并请他们设置。

在要求被取消之前，要求双重验证的团队的所有者不能在自己的账号上关闭双重验证。其他成员（管理员、成员和只读）可以看到该要求已开启，但不能更改。

## 移除成员与退出团队

- **移除成员。** 在 **成员** 表中点击此人旁边的 **移除** 并确认。他们会立即失去对团队网站的访问权限。所有者和管理员可以这样做，只有所有者才能移除所有者。
- **退出团队。** 所有者或管理员可以用同样的方式移除自己。最后一名所有者在有其他人成为所有者之前不能退出。成员或只读用户在控制台中没有这个按钮，请让所有者或管理员移除你。API 也允许任何成员用 `DELETE /api/teams/TEAM_ID/users/YOUR_USER_ID` 移除自己。
- **某人创建的网站。** 如果你把某人移出团队，他们会失去对自己所创建的团队网站的访问权限。这些网站仍属于团队。
- **注销账户。** 当你注销自己的账户时，你的个人网站会被删除，属于团队的网站则留在团队中。向你计费的团队网站会转给另一名所有者或管理员，优先选择付费套餐上的人。如果你是有其他成员的团队的唯一所有者，控制台会要求你先把另一名成员设为所有者。如果你是唯一的成员，团队及其网站会随你的账户一起删除。见 [账户安全](/docs/zh/security#注销账户)。

## 团队活动

所有者和管理员可以在团队中看到 **团队活动**。它列出成员加入、移除、角色变更、设置变更和网站变更，并注明操作人。你自己的登录和安全变更在你的 [账户活动](/docs/zh/security#账户活动) 中。

## 故障排查

- **创建团队和加入团队是灰色的。** 你的账号使用的是 Free 套餐。请在 **订阅** 页面升级。
- **加入时提示“Team not found”。** 邀请码有误或输错了。请让所有者或管理员从 **邀请码** 处重新复制。
- **成员看不到团队的网站。** 团队可能要求开启双重验证而该成员尚未开启，或者他们已被移除。
- **成员无法修改某项设置。** 他们的角色是 **只读**。所有者或管理员可以在 **成员** 表中修改。
