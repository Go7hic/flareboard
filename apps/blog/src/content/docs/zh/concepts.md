## 网站与网站 ID

**网站** 是所有数据的归属单位：它的事件、访客、用户、功能开关、会话回放、错误、日志和设置都属于某个网站。你在 **网站** 页通过 **添加网站** 创建它，需要填写 **名称** 和 **域名**。Free 套餐包含一个网站。

每个网站都有一个 **网站 ID**，是一个 UUID。追踪脚本和 HTTP API 用它来决定数据发往哪里。你可以在网站 **设置** 的安装代码中复制它：

```html
<script defer src="https://t.flareboard.dev/script.js" data-website-id="YOUR_WEBSITE_ID"></script>
```

网站 ID 不是机密。它在页面源码中可见，任何拿到它的人都可以向你的网站发送事件，所以请按“数据对外开放”来看待。如果希望能随时切断某个发送方，请使用 [项目密钥](#项目密钥)。

## 项目密钥

**项目密钥** 是某个网站的公开密钥，形如 `fb_pk_` 后面跟 24 个字母和数字。凡是可以填网站 ID 的地方都可以用它，它也是 PostHog SDK 的 API 密钥：

- 作为追踪脚本中的 `data-website-id`；
- 作为服务端调用 [采集 API](/docs/zh/reference/ingest-api) 时的 `website`；
- 作为 [PostHog SDK](/docs/zh/install/posthog) 的 API 密钥；
- 作为发送 OpenTelemetry 日志和链路时的 bearer 令牌或 `x-flareboard-key` 请求头。

和网站 ID 一样，把它放进网页是安全的。使用密钥的请求按密钥限流，而不是按访客 IP 限流，这更适合只从少数几个地址发送数据的服务器（见 [从服务端发送事件](/docs/zh/install/server)）。

查看方式：打开 **网站**，进入网站的 **设置**，**项目 API 密钥** 卡片会显示密钥和复制按钮。

要更换密钥，点击同一张卡片里的 **轮换密钥** 并确认。Flareboard 会签发新密钥，旧密钥在一分钟内失效。仍在使用旧密钥发送的内容（脚本代码、PostHog SDK、服务器）在你更新之前不会被记录。只有能编辑该网站的人才会看到这个按钮。

## 团队

**团队** 是共享网站的一组人。打开 **团队** 可以创建团队，或用访问码加入团队。用 **添加团队网站** 创建的网站属于团队：访问权限来自团队成员身份，而不是创建它的那个人。

团队成员有四种角色：**所有者**、**管理员**、**成员** 和 **只读**。只读成员可以查看数据但不能修改，用访问码加入的人默认是只读。在 Flareboard Cloud 上，团队功能需要 Cloud 或 Business 套餐。见 [团队与权限](/docs/zh/teams)。

## 访客

统计访客不使用 Cookie，也不存储 IP 地址。对每个请求，Flareboard 会对访客的 IP 地址、user agent、网站、盐值和服务端密钥计算一个单向哈希。盐值在每个日历月（UTC）开始时更换。因此：

- 同一网络下的同一浏览器，在整个月内算作同一个访客；
- 同一个人无法跨月关联起来；
- IP 地址在请求处理完后即被丢弃。

### 跨会话识别访客

如果你需要跨网络、跨月份识别回访的浏览器，请在网站 **设置** 的 **数据采集** 卡片中打开 **跨会话识别访客**。该选项默认关闭。

开启后，追踪脚本会生成一个随机 ID，保存在浏览器的 `localStorage` 中，并随每个事件发送。Flareboard 改为按这个 ID 而不是哈希来统计访客。这个 ID 是随机的，不是由 IP 地址或设备推算出来的。它会一直保留，直到访客清除该网站的数据。

由于这会在访客设备上存储一个标识符，根据访客所在地区，你可能需要先取得访客同意。关闭该设置即可回到不使用 Cookie 的统计方式：Flareboard 会忽略浏览器仍然发来的匿名 ID。页面也可以在脚本标签上加 `data-persistence="false"` 自行退出。

## 访问与会话

数据中有两个与时间相关的词，容易混淆：

- **会话** 标识某个网站上的一位访客。独立访客数就是基于这个 ID 统计的。对匿名访客，它来自上面说的哈希；对已识别的用户，或开启了访客记忆时，它改由网站和用户的 distinct ID 生成。
- **访问** 是这位访客的一次停留。

一次访问如何划分，取决于数据的来源：

| 来源 | 一次访问是 |
| --- | --- |
| 追踪脚本 | 每个浏览器标签页一次。从第一个事件起最长持续 30 分钟，之后的第一个事件会开启新的访问。 |
| 不带访问令牌的服务端事件 | 每位访客每个整点小时（UTC）一次。 |
| PostHog SDK | 一个 PostHog `$session_id`。没有它的事件（服务端 SDK）归入按小时划分的访问。 |

## 页面浏览与事件

**页面浏览** 是没有名称的事件。追踪脚本会在页面加载时和每次客户端路由切换时发送一次。

**自定义事件** 有一个名称（如 `signup` 或 `subscription_renewed`）和可选的属性。名称最长 50 个字符，一个事件最多带 100 个属性。在浏览器中用 `flareboard.track()` 发送，或用 [服务端 API](/docs/zh/install/server)。见 [追踪事件](/docs/zh/events)。

其他类型的数据走同一条管道：错误、日志、AI 调用、Core Web Vitals、热力图点击，以及脚本自动添加的 `$autocapture` 和 `$pageleave` 事件。

## 已识别的用户与用户画像

在你的代码告知访客是谁之前，访客都是匿名的。用户登录后调用 `flareboard.identify('user_123', { plan: 'pro' })`，会给访客附上一个 **distinct ID**，并在 **用户画像** 下创建或更新一份档案。你传入的属性会保存在这份档案上。只发送你愿意存储的内容，比如 ID 和套餐名称，不要发送密码或其他敏感数据。

需要了解：

- distinct ID 最长 128 个字符。
- 已识别的用户在每台设备上都使用同一个会话 ID，因此他们的行为可以对齐。
- `flareboard.alias()` 把之前的匿名 ID 与用户 ID 关联起来。开启访客记忆时，脚本会在 `identify()` 时自动完成这一步。
- `flareboard.group()` 把用户归入某个分组，比如公司或账号。
- 匿名访客没有档案，档案来自识别调用。

PostHog SDK 通过 `$identify`、`$set`、`$create_alias` 和 `$groupidentify` 遵循同样的模型。见 [使用 PostHog SDK](/docs/zh/install/posthog)。

## 版本与环境

错误、日志和 AI 事件可以带上 `release` 和 `environment` 标签，例如 `2.4.1` 和 `production`。在脚本标签上加 `data-release` 和 `data-environment`，或在调用时传入。有了它们，你可以按发布版本筛选错误和日志，功能开关也可以在定向规则中使用它们。它们只是普通标签：Flareboard 不会为每个环境分别保存数据集。想把生产和预发布分开，请创建两个网站。

## 数据保留

Flareboard 大约每小时删除一次超出网站保留期的原始事件和会话回放。各套餐设定了保留期上限：

| 套餐 | 最长保留期 |
| --- | --- |
| Free | 1 年 |
| Cloud | 2 年 |
| Business | 3 年 |

可以在网站 **设置** 的 **数据保留** 卡片中，通过 **原始数据保留天数** 设置更短的期限。留空则使用套餐上限。通过 OpenTelemetry 发送的日志和链路，无论什么套餐，最多保留 30 天。如果账号切换到保留期上限更短的套餐，更早的原始数据会被删除。

删除网站会立即把它从你的账号中移除，其所有数据会在 30 天内被清除。更多内容见 [隐私与数据](/docs/zh/privacy-data) 和 [套餐与限额](/docs/zh/plans-limits)。

## Cloud 与自托管

两者运行同一份代码。

| | Flareboard Cloud | 自托管 |
| --- | --- | --- |
| 运行位置 | 我们的 Cloudflare 账号 | 你自己的 Cloudflare 账号 |
| 地址 | 仪表盘 `https://flareboard.dev`，API `https://api.flareboard.dev`，采集 `https://t.flareboard.dev` | 你自己的仪表盘、API 和采集地址 |
| 套餐 | Free、Cloud 和 Business，有每月额度和保留期限制 | 所有功能，没有套餐限制 |
| 数据保留 | 受套餐限制 | 除非你设置期限，否则原始数据永久保留 |

本文档中的示例使用 Cloud 地址。如果你自托管，请换成你自己的地址。见 [自托管 Flareboard](/docs/zh/self-host/deploy)。
