你的 Flareboard 账户有专门的安全页面。它涵盖密码、双重验证、可用于登录的账号、已登录的设备，以及账户上发生的操作日志。

要打开它，请打开账户菜单（侧边栏底部你的名字），然后选择 **安全**。

## 密码

**密码** 卡片用于修改你登录所用的密码。

1. 输入 **当前密码**。
2. 输入 **新密码**（至少 6 个字符），并在 **确认新密码** 中再输入一遍。
3. 点击 **修改密码**。

修改密码会让其他所有设备退出登录，当前设备保持登录。

如果你忘记了密码，请在登录页面使用 **忘记密码？**。重置链接会发送到你账户上的邮箱地址。重置会让所有设备退出登录，但不会关闭双重验证。

通过 GitHub 或 Google 创建的账户在你设置密码之前没有密码，这类账户不显示 **密码** 卡片。要设置密码，请在登录页面使用 **忘记密码？**，链接会发送到账户上的邮箱地址。使用服务商登录时不需要密码。

## 双重验证

双重验证会在你每次登录时，除密码或服务商登录之外，再要求输入验证器应用中的 6 位验证码。它适用于任何支持标准基于时间的验证码（6 位，30 秒一个周期）的应用，例如 1Password、Google Authenticator 或 Authy。

### 开启

1. 在 **安全** 页面找到 **双重验证**，点击 **设置双重验证**。
2. 用验证器应用扫描二维码。如果无法扫描，请使用 **无法扫描？请手动输入此密钥**。
3. 在 **验证码** 中输入应用里的 6 位验证码，然后点击 **开启**。
4. Flareboard 会显示你的恢复码。点击 **全部复制** 或 **下载 .txt**，把它们保存在安全的地方，然后点击 **我已保存**。

你会得到 10 个恢复码。如果你丢失了验证器，每个恢复码可以让你登录一次。它们只在此时显示。Flareboard 以单向哈希保存恢复码，无法再次显示。验证器应用背后的密钥以加密形式保存。

### 用它登录

输入密码（或完成 GitHub、Google 登录）之后，输入 6 位验证码并点击 **验证**。如果你丢失了验证器，请点击 **使用恢复码**，改为输入一个恢复码。错误次数过多后，登录会被锁定一段时间，并显示“尝试次数过多，请稍后再试。”

### 恢复码

卡片会显示 **剩余恢复码**，并在数量不多时提醒你。点击 **重新生成恢复码** 可获得一组新的 10 个。输入一个验证码以确认。旧的恢复码会立即失效。

### 关闭

点击 **关闭**。Flareboard 会要求你输入密码（如果账户有密码）和当前的验证码。关闭双重验证后，登录又只需要密码。如果你是一个要求双重验证的团队的所有者，在你关闭团队的该要求之前，不能关闭自己的双重验证。见 [团队与权限](/docs/zh/teams)。

关闭双重验证会删除你的密钥和恢复码。

## 登录方式

**登录方式** 卡片列出 GitHub 和 Google，即可以登录你的 Flareboard 账户的其他账号。只有你的实例启用了某个服务商，或你已经绑定了它，才会显示该服务商。每一行显示 **状态**（**已绑定** 或 **未绑定**）以及绑定时间。

### 绑定服务商

1. 点击服务商旁的 **绑定**。你也可以在账户菜单中选择 **绑定 GitHub 账号** 或 **绑定 Google 账号**。
2. 在服务商的页面上批准访问。
3. 你会回到 **安全** 页面，并看到服务商已绑定的通知。此后即可用它登录。

Flareboard 保存服务商的账号标识，以及服务商返回的邮箱或用户名，不保存其访问令牌。一个服务商账号同一时间只能绑定到一个 Flareboard 账户。绑定属于其他 Flareboard 用户的服务商账号会被拒绝。

如果你用一个未绑定的服务商登录，只有当服务商和 Flareboard 都验证过同一个邮箱地址时，Flareboard 才会把它连接到现有账户。如果没有匹配的账户，Flareboard Cloud 会为该服务商创建一个新账户。自托管安装则会显示错误，并要求你用密码登录，再从账户菜单中绑定服务商。

### 解除绑定

1. 点击服务商旁的 **解除绑定** 并确认。
2. 你将不能再用该服务商账号登录。你可以随时重新绑定。

Flareboard 会拒绝解除你唯一的登录方式。如果账户是用该服务商创建的且没有密码，请先在登录页面用 **忘记密码？** 设置密码，再解除绑定。

## 已登录设备

**已登录设备** 卡片列出已登录你账户的浏览器。每一行显示 **设备**、你的登录方式（**登录方式**）、登录时间（**登录时间**）和最近一次使用的时间（**最近活动**）。设备是一个简短的标签，例如“Chrome on macOS”。Flareboard 不保存 IP 地址或原始 user agent。你当前的浏览器标有 **当前设备**。

- 点击某一行的 **退出登录** 可结束该会话。该设备必须重新登录。
- 点击 **退出所有其他设备** 可结束除当前会话外的所有会话。

会话在上次续期后持续 7 天。修改密码也会结束其他所有会话。如果你看到不认识的设备，请让它退出登录、修改密码，并查看 [账户活动](#账户活动)。

## 账户活动

**账户活动** 卡片是账户上所发生操作的日志，最新的在前。它记录：

- 登录和失败的登录尝试，包括登录方式和简短的设备标签；
- 密码修改和密码重置；
- 双重验证的变更，例如开启或关闭、重新生成恢复码和使用恢复码；
- 让某台设备或所有其他设备退出登录；
- 创建和撤销 API 密钥；
- 绑定和解除绑定登录服务商；
- 团队和网站相关的操作，例如创建或删除网站、导出数据和创建分享链接。

它不记录 IP 地址。卡片显示最近的 50 条记录。登录和失败登录的记录会在 180 天后删除。其他记录在账户存在期间一直保留。团队所有者和管理员还可以看到单独的 [团队活动](/docs/zh/teams#团队活动) 日志。

## API 密钥

个人 API 密钥让脚本和 AI 工具以你的身份行事。在账户菜单的 **API 密钥** 下创建和撤销它们。密钥不能创建其他密钥、修改你的密码、管理双重验证、会话或登录方式，也不能注销你的账户。这些操作需要你登录控制台。见 [REST API](/docs/zh/api#认证) 和 [MCP 服务](/docs/zh/mcp)。

## 注销账户

你可以自己注销账户。

1. 打开账户菜单并选择 **注销账户…**。
2. 在写着“输入 YOUR_USERNAME 以确认”的输入框中输入你的用户名（用你自己的用户名）。如果账户有密码，也要输入密码。
3. 点击 **注销账户**。

会发生什么：

- 你会在所有地方退出登录，你的 API 密钥失效，所有付费订阅被取消。
- 你的账户会立即关闭。你的个人网站、它们的分析数据、你的看板和链接会被删除。属于团队的网站留在团队中。
- 30 天宽限期结束后，所有内容会被永久清除。这包括你的会话、API 密钥、双重验证密钥和恢复码、已绑定的登录服务商、已保存的洞察、报告和报告订阅、助手对话以及你的账户记录。账单记录会按税务和会计法律的要求保留，通常为七年。见 [隐私与数据](/docs/zh/privacy-data)。
- 在 30 天过去之前，数据仍然存在。如果你是误删，请立即发邮件到 [support@flareboard.dev](mailto:support@flareboard.dev)。

在这些情况下，Flareboard 会阻止注销：

- 你是有其他成员的团队的唯一所有者。提示信息为“请先把 TEAM 的其他成员设为所有者，再注销账户。”请先让其他人成为所有者。如果你是唯一的成员，团队及其网站会随你的账户一起删除。
- 在自托管安装上，你是唯一拥有全局管理员角色的账户。请先让另一个用户成为管理员。
- Flareboard 无法取消你的订阅。此时不会有任何变化，你可以再试一次或联系支持。

如果只想删除一个网站而不注销账户，请在网站设置中使用 **删除网站**。同样适用 30 天的期限。

## 故障排查

- **我丢失了验证器。** 用恢复码登录，然后关闭双重验证并重新设置，或者重新生成恢复码。
- **我丢失了验证器和恢复码。** Flareboard 无法再次显示恢复码。请联系 [support@flareboard.dev](mailto:support@flareboard.dev)。
- **验证码被拒绝。** 应用中的验证码每 30 秒变化一次。检查手机的时钟是否设为自动，并输入当前的验证码。
- **我无法解除绑定 GitHub。** 它是你唯一的登录方式。请先用 **忘记密码？** 设置密码。
