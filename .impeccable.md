# Flareboard — Impeccable Design Context

## Design Context

### Users

Technical operators and developers who run websites on Cloudflare (or want to). They evaluate analytics during infrastructure decisions — comparing GA4 to edge-native alternatives, deciding between hosted Flareboard Cloud and self-deploy. In-product, they need dense, trustworthy dashboards for daily traffic monitoring across multiple sites.

### Brand Personality

**Precise · Edge-native · Operator-trusted**

Voice is direct and technical without hype. The product should feel like a serious devtool (Primer/Carbon density) with premium polish — not a marketing SaaS template. Cloudflare orange is a callout accent; Flareboard teal is the brand accent.

### Aesthetic Direction

- **Surface split:** Landing (`/`) uses editorial hierarchy, asymmetric bento grids, generous whitespace; authenticated shell uses VISUAL_DENSITY 7 (stat grids, mono numerics, tables).
- **Theme:** Light and dark via `[data-theme]` tokens in `global.css` — airy `#f4f6fa` light, blue-charcoal `#0a0d12` dark.
- **Typography:** Outfit (UI) + JetBrains Mono (data). Sentence case section titles; negative tracking on display headlines.
- **References:** Cloudflare developer docs trust, Carbon/Primer data density, editorial B2B devtool landing pages.
- **Anti-references:** Purple/cyan AI gradients, three equal feature columns, centered-everything marketing, glassmorphism decoration, generic Lucide-icon-above-heading cards, cookie-cutter pricing towers.

### Design Principles

1. **Flat solids only** — no gradients, colored glows, or mesh backgrounds. Hierarchy via type scale, spacing, 1px borders, accent rails, and `--shadow-sm` / `--shadow-md`.
2. **CSS variables exclusively** — never hardcode one-off colors; use tokens from `global.css`.
3. **Asymmetry over sameness** — landing bento and broken grids; dashboard 2-column site cards with clear KPI hierarchy.
4. **Operator density in-app** — tabular mono numbers, sparkline charts (hidden Y-axis OK), hover elevation on interactive cards.
5. **Cloudflare-native story** — pipeline (Ingest → Queue → D1 → Dashboard), stack roles, hosted vs self-host paths stay prominent in marketing.
